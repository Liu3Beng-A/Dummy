## 一、核心偏差修正（原整合文档的问题）

### 1.1 上一步重构的本质（重新理解）

上一步"地轨改为 J7（CAN_ID=7）"**不是简单的 CAN ID 改名**，而是把地轨从"特殊边缘节点"重构为"第 7 个关节 J7"的根本性架构变化：

| 维度 | 旧架构 | 新架构（已落地） |
|------|--------|------------------|
| **本质定位** | 地轨是"特殊边缘节点"（`motorJ[0]`，CAN ID=9） | 地轨是"第 7 个关节 J7"（`motorJ[7]`，CAN ID=7） |
| **MoveJ 格式** | `>Rail,j1,j2,j3,j4,j5,j6,speed`（地轨在第 1 位） | `>j1,j2,j3,j4,j5,j6,j7(rail),speed`（地轨在第 7 位，与所有关节对齐） |
| **$ 力矩格式** | `$c0(rail),c1,c2,c3,c4,c5,c6`（地轨在第 1 位） | `$c1,c2,c3,c4,c5,c6,c7(rail)`（地轨在第 7 位） |
| **runtime 索引** | runtime[0]=地轨, runtime[7]=夹爪 | runtime[7]=J7/地轨, runtime[8]=夹爪 |
| **motorJ[] 大小** | `motorJ[7]`（0~6） | `motorJ[8]`（0~7） |
| **ALL 代理位置** | 无（被地轨占用） | `motorJ[0]`（占位对象，nodeID=0） |

> **重要**：MoveJ/$ 格式变化是上一步重构的**核心目的**（让地轨对齐为"第 7 个关节"），不是配套改动。原整合文档完全遗漏这一点。

## 三、最终架构

### 3.1 对象布局（`dummy_robot.h`）

```cpp
class DummyRobot {
private:
    // motorJ[0]=ALL 广播代理 (ID=0, 占位)，motorJ[1..7]=J1~J7(含地轨 ID=7)
    CtrlStepMotor* motorJ[8] = {nullptr};

    // [v3.1] index [0]=ALL代理, [1..6]=J1~J6, [7]=J7/地轨
    static constexpr float AXIS_MAX_RPS[8] = {
        0.0f,    // ALL 代理（不参与速度规划）
        30.0f,   // J1
        30.0f,   // J2
        30.0f,   // J3
        30.0f,   // J4
        30.0f,   // J5
        30.0f,   // J6
        30.0f    // J7/地轨（直连丝杆1605）
    };

    // [v3.1] index [0]=ALL代理(无减速), [1..6]=J1~J6(50), [7]=J7/地轨(1, 直连丝杆1605)
    static constexpr uint8_t MOTOR_REDUCTION[8] = {1, 50, 50, 50, 50, 50, 30, 1};

    // [v3.1] runtime 索引: [1..7]=J1~J7/地轨, [8]=夹爪, [0] 空闲
    float jointAccRuntime[9] = {0};
    uint32_t jointAccLastUpdateMs[9] = {0};
    float jointCurrentLimitRuntime[9] = {0};
    uint32_t jointCurrentLimitLastUpdateMs[9] = {0};

    StepHand* hand = nullptr;  // 夹爪（ID=8），不在 motorJ[] 内
};
```

> **不需要 `#define Rail 7` 宏定义**：`motorJ[7]` 直接就是 J7/地轨，语义自明。

### 3.6 电机端 Rx 路由

```c
// HAL_CAN_RxFifo0MsgPendingCallback（35/42/57 电机同构）
uint8_t id  = (RxHeader.StdId >> 7);   // 7Bits ID (0~127)
uint8_t cmd = (RxHeader.StdId & 0x7F); // 7Bits CMD

// 单播：仅目标节点响应（任何 cmd，含 0x5C）
if (id == boardConfig.canNodeId) {
    OnCanCmd(cmd, RxData, RxHeader.DLC);
}
// 广播：id==0 且 cmd != 0x5C
else if (id == 0 && cmd != 0x5C) {
    OnCanCmd(cmd, RxData, RxHeader.DLC);
}
```

### 改动内容

```cpp
void CanSendMessage(CAN_context* canCtx, uint8_t* txData, CAN_TxHeaderTypeDef* txHeader)
{
    // 加固#1：发送前查 mailbox 空闲
    uint32_t startTick = HAL_GetTick();
    while (HAL_CAN_GetTxMailboxesFreeLevel(canCtx->handle) == 0) {
        if (HAL_GetTick() - startTick > 5) return;
    }

    // 加固#2：10ms 超时
    osStatus semaphore_status;
    if (canCtx->handle->Instance == CAN1)
        semaphore_status = osSemaphoreAcquire(sem_can1_tx, 10);
    else if (canCtx->handle->Instance == CAN2)
        semaphore_status = osSemaphoreAcquire(sem_can2_tx, 10);
    else
        return;

    if (semaphore_status == osOK) {
        HAL_StatusTypeDef ret = HAL_CAN_AddTxMessage(
            canCtx->handle, txHeader, txData, &canCtx->last_heartbeat_mailbox);
        // 加固#3：失败时释放信号量
        if (ret != HAL_OK) {
            if (canCtx->handle->Instance == CAN1)
                osSemaphoreRelease(sem_can1_tx);
            else if (canCtx->handle->Instance == CAN2)
                osSemaphoreRelease(sem_can2_tx);
        }
    }
}
```
