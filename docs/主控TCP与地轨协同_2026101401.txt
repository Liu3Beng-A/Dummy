主控有限 MoveL、TCP 工具坐标与地轨协同交付说明（2026-10-14）

当前交付范围
============
先完成有限目标点的原生主控 MoveL。主控负责 TCP 插补、逆解、限位与动态预检，以及七轴 50 Hz q/v/a 段的持续供给；电机本地按原有 20 kHz 定时执行参考曲线。
普通上位机不恢复 PC IK/连续 MoveJ 模拟，不通过切换公开模式7来运动。默认主控模式2保留。公开模式7仍仅供独立 OPEN→CLOSE、恒定原地曲线诊断。
TCP 标定、固定 TCP 手动移轨、连续手柄/鼠标 MoveL、INT 途中无缝重规划及 TRJ 笛卡尔连续混合均未实现。新固件确认能力后，上位机禁止连续 MoveL 输入；单点 MoveL、MoveJ、夹爪和离线预览保留。
SEQ 与 TRJ 可排队有限目标，但每个有限 MoveL 在实际到位后才完成；此版本不承诺模式3连续混合。INT 的新指令在原生轨迹执行/关闭/到位确认期间明确拒绝，请等待完成或 STOP。
改前全量快照提交 4148f68。后续实现仍留在工作区；没有新增提交、连接设备或烧录。

模型与坐标约定
==============
新尺寸均来自用户最新法兰图：L_BASE=207.3、D_BASE=0、L_ARM=170、D_ELBOW=69.5、L_FOREARM=117、L_WRIST=113 mm。
夹爪两指中心先采用法兰局部 +Z 114 mm，独立作为工具变换，未将 114 mm 加进 DH wrist。
完整工具偏移 XYZ 与 ABC 可设置。ABC 的数学约定为 Rz(C)*Ry(B)*Rx(A)，正向工具 Z 的实际安装方向仍需用户对照实物确认；本轮没有测量或标定夹爪。
对外串口 XYZ=mm，ABC/joints=deg，地轨=mm；纯运动学内部 XYZ=m。FK 与 IK seed 的关节角统一为度，新米制 IK 接口与旧毫米制 IK 包装分开。
世界 TCP = T_world_base(rail)*T_base_flange(joints)*T_flange_tcp(tool)。地轨沿世界 +Y，主控逻辑限位仍 -250～250 mm、5 mm/电机圈、inverseDirection=true。J7 触碰主控 -250 端再回0的既有方向改动保留。
新模型基座高度比旧165 mm增加42.3 mm。历史笛卡尔点可能需要重新核对/示教；不会把旧保存点自动平移。关节点不按42.3 mm更改。
PC 纯算法、手柄FK和可视化坐标桥同步尺寸；导出模型基准高度227.3 mm相对新数学基准的 marker 偏移为20 mm。灯罩、RGB浮窗、虚实显示等并行视觉改动保持。

主控实际工作流程
================
1. 串口只接收有限目标，严格解析后进入串行命令任务，保留原任务ID/运动epoch。旧 @ 是基座法兰目标，新 @T 是世界TCP目标。
2. 原生生产者取得独占会话，只发 OPEN 并确认七轴准入；未自动使能，不把被拒 OPEN 当已启动。
3. 逐轴读取同会话新鲜 DIAG7 锁存整数参考，作为精确 SEED。GUI关节回读的刷新延迟不参与这个起点确认。
4. PRECHECK：先固定当前地轨，求整条 TCP 直线和姿态短弧的连续六轴解，检查真实关节限位、解析残差、分支连续性、量化后的20 ms曲线几何与动态边界。
5. 仅固定地轨几何/限位/连续性不能通过且 rail_auto=1 时搜索协同地轨：优先沿目标方向尝试约30/60/120/200 mm的整段位移，再做有界粗搜索；地轨硬限位内保留5 mm规划余量。轨迹从当前轨位平滑变化到候选终点，六轴同步补偿。固定轨仅动态失败时只尝试降低轨迹速度，不为它移动地轨。
6. BUFFER：整轨预检成功后供给50 Hz整数 q/v/a 段，先缓冲，再请求同步 START。START_PENDING 和实际 RUNNING 分开显示。
7. RUNNING：生产者按空位持续补给，内部真实进度更新心跳；只读界面查询不能制造生产者心跳。电机以现有20 kHz整型曲线执行。此过程不发送普通MoveJ目标命令0x07。
8. 等待七轴执行 END/COMPLETED 后 CLOSE 原会话，待全部关闭确认；迟到 CLOSE 只允许清理，不自动 START 或恢复运动。关闭未确认仍保持所有权并阻止新运动。
9. SETTLING：用现有带 nonce 的关节目标/实际到位协议再确认实际到位。整数终点到 float 电机圈数的转换保证回转整数不丢一微步。缺少 TARGET_READY 时不补发普通0x07。
10. 只有关闭和实际到位均确认才 stage=DONE，并返回对应 ok MOVEL。人为 STOP 为 CANCELLED/code12；自动到位失败保留 TARGET_READY_TIMEOUT 等原因，code17。更早的真实电机/CAN/关闭故障不被泛化 STOP 文案覆盖。

规划资源边界
============
固定129×7关节节点和显式深度栈；没有递归、没有整轨动态内存分配。几何预检用 Bernstein 控制点包络、FK中点和连杆位移上界逐段细分，不只检查 IK 端点。
最大6000段，即120秒参考时长；有限工作预算180000、规划墙钟30秒；间歇检查STOP并让出CPU。超预算/不可达/跳支/动态或几何边界无法通过时拒绝，不发送START。
TCP几何参考边界为1 mm/1°，包含编码量化余量；这是模型与参考轨迹界限，不是实机定位精度承诺。没有新增碰撞检测，几何可达不等于无机械干涉。
速度档位1～100参与笛卡尔时间规划：名义线速度为同值 mm/s，姿态名义上限0.45×档位 deg/s；S形起停并按关节限速/加速度/jerk再延长时长。不是把档位直接写成普通MoveJ速度。当前保守六轴上限40 deg/s、80 deg/s²（受电机实际参数进一步约束），地轨20 mm/s、40 mm/s²。
轨道协同为有界可行解搜索，并非全局最优冗余优化。接近奇异/关节限位或需不连续换支的整段路径可能拒绝，不能靠移动地轨保证所有目标都可达。

协议与工具设置
==============
旧：@x,y,z,a,b,c[,speed] —— 基座法兰，固定当前地轨，继续兼容旧工具。
新：@T x,y,z,a,b,c,speed,rail_auto —— 世界TCP，使用主控当前工具；rail_auto只能0/1。
新扩展：@T x,y,z,a,b,c,speed,rail_auto,tx,ty,tz,ta,tb,tc —— 世界TCP，携带本次工具快照；不改主控持久工具。新版Dummy上位机确认能力后发送这一格式，与本地工具设置一致。
新协议最大159有效字符，速度1～100，工具XYZ每项±500 mm；拒绝非有限值、非法浮点、字段数量与尾随垃圾。原普通MotionValues 63字节/8字段契约保留。
#KIN_CONFIG：尺寸、坐标、版本与 @T 能力。仅精确 KIN v=2 确认新能力；断开/重连清除能力，旧固件查询错误不能升级能力。
#TOOL：读取工具定义与 rev/dirty/storage。
#TOOL_SET 0,0,114,0,0,0：只在空闲时设置RAM工具。
#TOOL_RESET：空闲时恢复标称工具；不立即写Flash。
#TOOL_SAVE：必须确认 DISABLED 且空闲后才显式保存。
#TCPPOSE：由主控当前实际关节缓存计算世界TCP（两行XYZ/ABC）；测试前等回读稳定，记录同一静止姿态。
#IKCHECK 0,10,80,0,90,0：只做FK/IK回环，报告有效分支和wall_us，不启动运动；原生轨迹活动时拒绝该计算查询。
#CARTESIAN_STATUS：所有权、状态、数字原因、提交/执行进度、故障阶段/节点/序号/时龄/CAN命令及规划耗时/参考边界。
其中code是底层执行器协议原因，plan/reason文本是规划或到位结果；NO_IK等规划拒绝可能同时code=0，不能将其当运动成功。仅匹配本次任务ID的DONE及ok MOVEL才确认完成。
#STACK：现有任务栈历史余量和FreeRTOS heap/heap_min。
旧串口助手的单点 @ 仍是法兰坐标，手工输入支持新查询及 @T；新固件关闭 MoveL 拖发，保持 MoveJ/夹爪与旧固件行为。

工具存储
========
TCP记录在0x080FFB00，RGB在0x080FFC00，同在保留的Flash sector11。单工具槽、版本+CRC，RAM脏标志和已保存记录分开。
保存任一项时保留另一项已保存的原始记录，不顺带保存其未保存RAM修改；两项共享Flash写互斥门禁。默认/损坏CRC/写失败均有状态，不将坏工具当有效。
代码区仍只896 KiB，BIN/HEX不覆盖参数区。正常按代码镜像烧录，不选择整片擦除；整片擦除会删除原有电机参数/零位/RGB/工具。

20 kHz执行耗时说明
=================
F103一般曲线准备改为直接Q40系数映射，移除原准备中的软件double除法；Curve::Build栈帧从264降到176 B。恒定曲线快路径仍保留。
与13.05的链接ARM对比，已检查的40个执行/编码器/进入准入相关热函数指令及栈帧保持；20k Tick不新增浮点、堆分配或64位除法。
这不能证明整个20 kHz IRQ最坏耗时小于50 µs，尤其此前现场准备计算与编码器/控制中断可能已接近预算。也没有测量F405实际IK或整轨预检的板上耗时。本次加入IKCHECK wall_us与CARTESIAN规划us，保留电机DWT诊断，供首轮实测。
DIAG每条等STREAM_NODE回包再发下一条。电机72 MHz时cycles/72=µs；DIAG15为最大tick周期gap，包含实际中断间隔，不当纯函数耗时。诊断为上电以来最大值/累计量，不自动清除。
单节点前后读：#STREAM_DIAG N 2（准备最大周期）、9（控制最大周期）、12（控制迟到次数）、15（控制最大gap周期）、3（最小栈余量）、19（最大RX时龄tick）。可加21（编码器最大周期）、22（闭环内核最大周期）。20 kHz时tick/20=ms。
若控制耗时达到3600cycles（50 µs），或相同短轨迹测试后迟到次数继续增加，保留日志停止扩大测试，不能拿离线通过替代实机预算。gap仅比3600略大可能是中断起始抖动，不能单凭这个最大值断言漏周期；达到7200cycles（两个周期）则需要调查。历史已有计数以本次测试前后增量判断，首次烧录后空闲也需基线。

用户烧录与分步验收
==================
本任务不烧录。全部镜像位于 E:\Dummy-code\firmware_artifacts，无另一套按模式隔离目录。主控用 Core-STM32F4-fw；J1～J7按各驱动板现有35/42/57硬件类型配套相应motor文件，不按关节号猜类型。J7仍用原57类型。夹爪不参加七轴Cartesian，可保留当前兼容版本；motor-gripper同批已提供。
不要仅烧主控就开始新非零七轴曲线。本次一般曲线准备优化位于电机端，J1～J7均需匹配新版。保持各板节点ID、方向、零位与保护参数。

A. 重启新上位机、默认主控模式2。先 DISABLED，依次查询 #FW_VERSION 0、各节点 #FW_VERSION N、#KIN_CONFIG、#TOOL、#STACK，每条等end再发下一条，核对release/buildset、工具114和轨限位。#IKCHECK做常用非奇异关节姿态，只读不运动。保存整份日志。
B. START后先用熟悉的普通MoveJ到安全、无碰撞、非奇异姿态，等真实到位；读取主控实际 #TCPPOSE。原J4 OPEN→CLOSE及七轴恒定原地诊断可先各一轮核对通路，仍使用独立测试入口，不与Cartesian同时运行。
C. 对当前报告的TCP发送一条同位姿有限 @T，speed=5、rail_auto=0。预期OPEN/PRECHECK/BUFFER/START_PENDING/RUNNING/SETTLING/DONE，最终对应ok MOVEL。#CARTESIAN_STATUS owner=0、code=0，七轴收齐、CLOSE确认、没有STOP或普通MoveJ补发。GUI显示刷新滞后不等于主控未供给，按主控stage和序号判断。
D. 用同一新鲜静止TCP，只改X正向5 mm、姿态不变、speed=5、rail_auto=0，一条完成后再回原点。随后Y/Z各±5 mm，每次先确认实际机械可运动方向。通过要求：地轨原位、姿态基本保持、末端连续小直线、无顿挫/嗡鸣明显增加/UNDERRUN/同步故障，最终确实到位。记录规划us、#STACK及J1～J7上述DWT前后值。
E. 小距离通过后，沿已确认方向逐次测speed5/10/20以及20～30 mm；不一下改成大范围或极限速度。中途STOP一次，要求无DONE误报，七轴受控停止、锁定、新目标被拒，按既有START流程恢复后才能下一条。
F. 最后才启用rail_auto=1。先同一六轴可达的小路径，确认地轨仍不动；再选择已核对的接近六轴工作边缘、固定轨预检会拒的温和目标，确认整段一次较大移轨并同步保持TCP直线。不要照搬离线±350 mm用例到实机。请提供起始七轴、目标TCP及完整日志后选择具体边界测试点。
任何一级未通过，停在该级保存完整日志。拒绝时重点发 #CARTESIAN_STATUS、#MOTION_STATUS、对应 #STREAM_DIAG 和 #STACK；无需先调PID/电流、无需重复大轨迹或擦除零位。
