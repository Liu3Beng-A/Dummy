# 模块 13 — 架构常量（DH 参数 / 减速比 / 速度限幅 / REST_POSE / 默认值）

> **范围**：机械臂/电机的物理与几何常量集
> **关联文件**：
> - `Robot/instances/dummy_robot.h`（常量定义集中地）
> - `Robot/actuators/ctrl_step/ctrl_step.cpp` (`SetPositionWithMotorRps` 重命名)

---

## 模块概述

架构常量分 4 类：

| 类型 | 含义 | 示例 |
|---|---|---|
| 几何 | DH 参数 / 物理尺寸 | `DH[6]` |
| 减速比 | 电机端减速到输出轴 | `MOTOR_REDUCTION[8]` |
| 速度限幅 | 各轴物理上限 | `AXIS_MAX_RPS[8]` |
| 默认值 | 默认零位 / 默认速度 / 默认加速度 | `REST_POSE / DEFAULT_JOINT_SPEED` |

## 决策

| # | 决策 | 理由 | 风险 |
|---|---|---|---|
| 1 | **DH 参数使用新值** | 新机械结构 | 迁移需重新标定 |
| 2 | **`MOTOR_REDUCTION[8] = {1,50,50,50,50,50,30,1}`** | 硬件升级后减速比统一 | 无 |
| 3 | **`REST_POSE J2 = -75°`** | 机械结构调整 | 旧标定文件需重新记录 |
| 4 | **`DEFAULT_JOINT_SPEED = 80`** | slider 默认值提高 | 旧版 30 |
| 5 | **`DEFAULT_JOINT_ACCELERATION = 150.0f`** | 单位统一后 r/s² | 与 `FALLBACK_JOINT_ACCELERATION` 不同：FALLBACK 是查询未回包的兜底 |
| 6 | **`SetPositionWithMotorRps` 重命名保留**（决策 §0.3 D1 ✅） | `rps` 比 `vel` 语义精确 | 无 |
| 7 | **`ALL = 0`**（广播代理 ID） | motorJ[ALL] 是 0 号占位电机 | 无 |
