# 模块 07a — 灯效配置（`!RGB_*` ASCII 命令 + 亮度/模式/颜色）

> **范围**：RGB 灯效的用户可配置命令（开机/使能/失能灯效 + 亮度 + 模式 + 静态颜色）
> **关联文件**：
> - `UserApp/protocols/ascii_protocol.cpp` (`!RGB_SET_START/ENABLE/DISABLE/BRIGHT/MODE/COLOR`)
> - `Bsp/gpio/rgb.cpp/.hpp` (RGB LED 驱动，硬件层)

> **说明**：本模块只关注"用户能配置什么"（灯效配置）；**灯效状态码如何控制 RGB 行为**见模块 [07b - RGB 状态机](firmware_new主控固件模块07b_RGB状态机.md)。

---

## 模块概述

RGB 灯效不是装饰，是故障指示：
- **开机默认灯效**（rgbStateStart）：用户希望开机看到喜欢的颜色
- **使能时灯效**（rgbStateEnable）：电机使能时什么颜色
- **失能时灯效**（rgbStateDisable）：电机失能时什么颜色（通常红色 = 警告）
- **亮度**：0~255 可调
- **模式**：0~9 灯效模式（流水、呼吸、纯色等）
- **静态颜色**：3 组可配置 RGB 值

每条 `!RGB_*` 命令同时持久化到 EEPROM（详见模块 [16 - EEPROM](firmware_new主控固件模块16_EEPROM配置持久化.md)）。

## 决策

| # | 决策 | 理由 | 风险 |
|---|---|---|---|
| 1 | **保留全部 6 条 `!RGB_*` 命令** | 用户已配置好的灯效偏好需要保留 | 灯效配置与模块 [07b - RGB 状态机](firmware_new主控固件模块07b_RGB状态机.md) 是耦合点 |
| 2 | **`SaveConfig()` 持久化**（已生效） | 配置需断电保持 | 详见模块 [16 - EEPROM](firmware_new主控固件模块16_EEPROM配置持久化.md) |
| 3 | **USB 双重匹配冗余待清理** | ascii_protocol.cpp 中 `!RGB_SET_*` 在前/后两次匹配，功能正确但代码冗余 | 无功能影响，可清理一处 |
| 4 | **`!HAND_EN` 多回一行 isEnabled 状态的差异** | USB 版多回一行（与 UART4 行为不一致） | 已知小问题，不影响功能 |

**注意 USB 双重匹配**（待清理）：
- `!RGB_SET_START` 在 line 50 和 line 241 都匹配（功能正确但冗余）
- `!RGB_SET_ENABLE` 在 line 64 和 line 255 都匹配（同上）
- `!RGB_SET_DISABLE` 在 line 78 和 line 269 都匹配（同上）

**禁止事项**：
- ❌ 不要删除任何 `!RGB_*` 命令（用户已配置偏好）
