# 模块 08 — 夹爪控制（`!HAND_*` ASCII 命令 + DummyHand/StepHand 类设计）

> **范围**：夹爪（手爪）的所有 ASCII 命令 + 主控侧夹爪类抽象
> **关联文件**：
> - `UserApp/protocols/ascii_protocol.cpp` (`!HAND_ZERO/EN/DIS/POS/O/C`)
> - `Robot/instances/dummy_robot.h/cpp` (`DummyHand` 旧 vs `StepHand` 新)
> - `Robot/actuators/ctrl_step/ctrl_step.hpp` (`StepHand` 类继承 `CtrlStepMotor`)

---

## 模块概述

夹爪是机械臂末端执行器，独立于 6/7 关节。控制维度：

| 命令 | 功能 | 行为 |
|---|---|---|
| `!HAND_ZERO` | 标定 | 等待 `AllAtTarget(2.0f)` ≤10s 后 `ApplyPositionAsHome()` |
| `!HAND_EN` | 使能 | `hand->SetEnable(true)` |
| `!HAND_DIS` | 失能 | `hand->SetEnable(false)` |
| `!HAND_POS` | 位置控制 | `hand->SetAngle(0~100)`（0=闭合, 100=张开），越界回 error |
| `!HAND_O` | 张开（力矩） | 力矩透传张开（电流 -1） |
| `!HAND_C` | 闭合（力矩） | 力矩透传闭合（电流 +1） |

**类设计**：OLD 用 `DummyHand`（裸 CAN 发帧），新固件用 `StepHand`（继承 `CtrlStepMotor` 复用全部接口）。

---

## 三状态对比

| 维度 | OLD | firmware | 当前 firmware_new |
|---|---|---|---|
| 夹爪类 | `DummyHand`（裸 CAN，ID=7） | `StepHand`（继承 `CtrlStepMotor`，ID=8） | **StepHand 已生效** |
| 夹爪 ID | 7（旧约定） | 8（避开地轨 ID=7） | 8 |
| `!HAND_ZERO/EN/DIS/POS` | 无 | 4 条命令已实现 | 保留 |
| `!HAND_O/C` 力矩控制 | 无 | 透传张开/闭合 | 保留 |
| `!HAND_EN` 多回一行 isEnabled | 无 | USB 多回一行 | 保留（已知小问题） |
| 标定等待 | 无 | 等待 `AllAtTarget(2.0f)` ≤10s | 保留 |

---

## 决策

| # | 决策 | 理由 | 风险 |
|---|---|---|---|
| 1 | **保留 `StepHand` 继承 `CtrlStepMotor`** | 复用电机接口（SetAngle/SetEnable/Query等） | 无（已生效） |
| 2 | **保留全部 6 条 `!HAND_*` 命令** | 夹爪功能完整 | 无 |
| 3 | **保留夹爪 ID=8** | 避开地轨 ID=7（ALL 代理 0；J7/地轨 7） | 无 |
| 4 | **`!HAND_EN` USB 多回一行差异**：暂时保留 | UART4 vs USB 回执差异是已知小问题 | 无功能影响 |
