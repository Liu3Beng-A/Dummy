# 模块 12 — 校准与归零（`!CALIBRATION` 删除 + `#OFFSET_J` 单轴归零）

> **范围**：机械臂位置标定（绝对位置 → 相对零位）
> **关联文件**：
> - `UserApp/protocols/ascii_protocol.cpp` (`!CALIBRATION` 旧 / `#OFFSET_J` 新)
> - `Robot/instances/dummy_robot.h/cpp` (`CalibrateHomeOffset()` 旧 / `ApplyPositionAsHome` 旧）

---

## 模块概述

"归零"是把当前位置定义为"零位"，让电机后续按相对偏移运行。

| 方案 | 时机 | 优点 | 缺点 |
|---|---|---|---|
| 全轴归零 `!CALIBRATION` | 一次标定 6 关节 | 简单 | 不灵活；不需全归零时也得跑 |
| 单轴归零 `#OFFSET_J <id>` | 按需标定单轴 | 灵活 | 需手动选轴 |
| 电机端本地归零 | 电机端 0x15 单独下发 | 主控不参与 | 主控侧需 0x23 回包校准 `currentJoints` |

OLD 用 `!CALIBRATION`（全轴），新固件用 `#OFFSET_J`（单轴 + 可批量 `all`）。

## 决策

| # | 决策 | 理由 | 风险 |
|---|---|---|---|
| 1 | **删除 `!CALIBRATION` 全轴标定**（决策 §0.2 D1） | `#OFFSET_J` 单轴更灵活 | 无 |
| 2 | **删除主控驱动 `DoCalibration()`**（决策 §0.2 D4） | 校准应在电机端本地完成 | 无 |
| 3 | **`#OFFSET_J` 单轴归零保留** | 灵活 | 无 |
| 4 | **0x15 ApplyPositionAsHome 行为**：等待电机端固件修复（同步 `realPosition`） | 详见电机固件决策 | 待电机端 |
