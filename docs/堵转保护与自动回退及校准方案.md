## 3. 当前源码已确认事实（前一轮核查，实施前按当前行号复核）

### 3.1 STOP

- 主控 `Robot/instances/dummy_robot.cpp` 的 RequestSoftStop/RequestStart/RequestDisable/PollSoftStop：运动世代取消旧任务、清队列，以 token、节点阶段和有限位置确认状态；STOP 收集 J1～J7，DISABLE 收集 J1～J8。START 包括 QUERY 与 ENABLE_HOLD，pending 只表示接受请求，最终 ok 才是完成。
- 主控 `dummy_robot.h`：冷启动为 DISABLED；NORMAL 与 DISABLED 以外阶段属于 STOP 锁定。USB/UART 入口已统一检查锁定。现有锁定入口中的 STOP 顺序需要在融合时调整，使重复 STOP 可以打断内部回退。
- 电机 `Ctrl/Motor/motor.cpp` 的 RequestSoftStop/TickSoftStop/CaptureStopPosition：使用本地 ratedAcceleration 减速；停稳后一次捕获 realPosition，位置保持不逐周期追随 estPosition。
- 20kHz STOP 判稳：参考速度归零后，50ms 窗口真实位置峰峰值≤8 内部单位，估计速度有符号均值的绝对值≤0.01 电机 r/s。此窗口用于判稳，不等同于回退目标实际到位；回退还必须验证真实位置误差及位移。
- 电机内部 51200 单位/电机圈；J1～J5 减速比 50，J6 为 30，J7 为 1、导程 5mm/r。正逻辑地轨方向经过 inverse 转换，不能直接硬编码为正电机速度。
- `firmware_new/stop_protocol.h`：CAN 标准帧 ID `(nodeID << 7) | cmdCode`；0 为 ALL。0x0A 现有 QUERY/STOP/RELEASE/ENABLE_HOLD/DISABLE 数值和确认语义应保留。

### 3.2 新版已有基础保护

- `Ctrl/Motor/motor.cpp` 旧检测使用 focCurrent 命令值、低估速和约 1 秒计时，旧计时复位不等同于严格三条件连续成立。
- isStalled 会令驱动 Sleep，同时阻止 ENABLE_HOLD；该标志还被电角度编码器校准流程使用。它不能直接作为新“可回退、可保持、可由 START 解锁”状态。
- softNewCurve 清除旧 isStalled；新版保护必须单独锁存，普通新目标不能清除保护。
- estPosition 含速度前馈；DCE 的位置误差被限幅。堵转跟随误差应使用未限幅的实际位置与当前参考差值，不能复用限幅后的 PID 误差。
- focCurrent 是输出给驱动的**电流命令值**，不是 ADC 实测电流。方案、查询、界面均须使用这一名称。
- MT6816 当前校验失败可能保留旧角度，IsCalibrated 只说明校正表有效，不能证明本次反馈有效；SPI HAL_MAX_DELAY 也不满足保护动作有界等待要求。
- 电机 CAN 发送失败可能进入 Error_Handler；接收只向本机和 ALL 分发，不会自动接收其他节点的保护事件。保护发送及联动需要专门的非阻塞路径和有效性检查。
- 主控 TryCanSendMessage 当前会拒绝 STOP 锁定状态；普通 CanSendMessage 对 0x0A/0x23 有例外。内部保护帧必须明确纳入允许列表，避免锁定自己的保护通信。

## 4. 推荐职责与融合状态机

### 4.1 电机端

在 20kHz 控制路径内持续检测、严格连续计时、锁存本次事件并撤销旧目标。首先本地软停和固定位置保持；即使主控未收到事件，也不能继续冲向旧目标。

保持可重发的每节点事件记录，带会话/事件编号、状态、失败原因；收到事件确认只停止相应重发，不解除保护。只有收到主控本次有效的回退授权、机械范围配置及有效反馈，才执行内部回退。

回退使用独立规划上下文。禁止改写普通 ratedVelocity、ratedAcceleration、正常电流限制或 PID 后忘记恢复。限制回退实际输出电流及相关积分；普通参数在所有退出路径保持一致。

### 4.2 主控端

收到事件立即设置运动入口锁定和取消世代；CAN ISR 仅记录事件/快速门禁，队列清理、状态转换、输出在任务中进行。撤销 SEQ/INT/TRJ/TUN 旧运动、队列、旧目标、未完成系统任务及迟到帧。

联动停止 J1～J7，收齐有效停稳位置后，按机械范围和方向配置授权回退。推荐**一次只回退一个节点**，其余节点保持。多节点的机械兼容性无法确定时不假定安全，报 MULTI_STALL_CONFLICT 并保持；任一回退失败，取消剩余计划并逐节点报告原因。

回退完成/失败后同步真实保持位置，重新播种主控目标、规划起点与到位状态。START 只解除锁定并保持捕获位置，不恢复堵转前目标。

### 4.3 状态与关键转换

采用现有 STOP 状态机扩展保护原因和内部阶段，避免两套控制器同时给电机发目标。下列为语义状态，最终枚举命名待实现时确定：

| 状态/事件 | 动作与去向 |
| --- | --- |
| NORMAL + 堵转事件 | 立即运动锁定、清旧任务；PROTECT_STOPPING；七轴联动软停 |
| PROTECT_STOPPING + 全部停稳、范围和方向有效 | 等待/执行本次授权的 RETREATING |
| RETREATING + 单节点实际到位并判稳 | 捕获位置并 HOLD；下一节点或 PROTECT_HOLD_SUCCESS |
| 任一准备/回退异常 | 取消余下授权、软停可控节点并固定保持；PROTECT_HOLD_FAILED，报告原因 |
| 回退成功 + 没有提前 START | 保持锁定，等待 START/DISABLE |
| 回退成功 + 提前 START | 七轴最终位置同步并确认保持后自动解锁；Started ok |
| 准备/回退中 + START | 仅记录 pending，不打断回退、不恢复旧目标 |
| 回退失败 + 先前 pending START | 清 pending，不自动解锁；要求新的明确 START 或 DISABLE |
| 回退成功/失败保持中 + 新 START | 反馈、范围、节点健康且保持确认成功后解锁；仍不可安全保持则明确失败并维持保护 |
| 准备/回退中 + STOP | 撤销回退授权、待执行回退与 pending START；七轴软停、捕获当前停点，转用户 STOP 锁定，不再次自动回退 |
| 任意阶段 + DISABLE | 最高用户优先级；撤销授权和 pending START，八轴失能确认；Disabled ok 后解除锁定 |
| 用户 STOP 减速中 + START | 沿用现有 STOP：记录 pending，七轴停稳固定后保持解锁 |

STOP、DISABLE 的撤销编号必须使迟到 GO/续约/目标失效。重复 STOP/GO/事件应幂等；重复回退授权不得再次增加 5°/5mm 距离。DISABLE 已受理不能被较低优先级请求覆盖成重新运动。

无有效反馈时不能声称固定位置保持成功；健康反馈下承重关节使用位置保持及原有合理电流限制，不默认断电。无反馈时只能进入不可定位保护并报告，机械承重需要实际机械支撑；电气制动不能宣称等同机械抱闸。

三条件为：滤波后的绝对电流命令≥阈值、绝对实际速度≤阈值、未限幅实际跟随误差≥阈值，且当前模式/运动意图适用。全部连续成立才计时；任一条件失效立即清零候选计时，不累计间歇满足时间。锁存的保护不随条件失效自动解除。

启动豁免只适用于从静止开始的有效新运动，不应每次 INT/SRV 数据包重置，否则连续目标更新会永久豁免。模式切换、参数变化、方向变化复位候选计时；STOP/DISABLE 取消普通候选检测；START 解锁后重新建立启动上下文，不能清掉尚未处理的锁存保护事件。

静态承重、高电流命令且零速不独立构成堵转。必须有适用运动意图/跟随误差，避免位置保持误触发。持续运行保护的范围不能仅由“模式枚举存在”推断。

## 6. 自动回退的安全边界与完成条件

- 方向取触发前稳定参考运动方向的反向，结合实际运动历史及未限幅误差检查。方向不可确定时 NO_DIRECTION，不默认选择正方向。
- 将 5°/5mm 转为每节点电机绝对编码器目标，统一坐标系；不得把已包含 homeOffset 的绝对目标再次送入自动加偏移的普通 setter。
- 目标受本机有效位置范围、方向许可、机械约束限制；空间不足时允许截短并报告请求距离/实际距离，低于最小有效位移报 NO_SPACE。软件关节限位不能证明整臂无碰撞。
- 地轨沿用 −250～+250mm，关节沿用当前各轴限制；校准改变坐标原点后必须重新同步范围配置与版本，否则禁止授权回退。
- 距离为上限，速度为上限。J1～J5 的 5°折合 0.6944 电机圈，J6 为 0.4167圈；在 5r/s² 下为三角速度曲线，峰值约 1.863/1.443r/s，通常达不到 3r/s 上限。
- J7 的 5mm 折合 1 电机圈，0.5r/s、5r/s² 下规划时间约 2.1 秒，另需判稳及通信时间；故使用用户确认的 5 秒超时。
- 成功必须同时满足：内部参考速度归零、**实际编码器位置**进入目标容差、实际位移有效、现有 50ms STOP 稳定窗口成立。仅 softPosition/softVelocity 达目标不算成功。
- 再次受阻、实际到位超时、无方向、无空间、无有效编码器、范围版本无效、授权超时/撤销、节点离线都应分别报告。禁止循环回退或隐式不断重试机械动作。
- 用固定捕获位置保持，不能 LOCKED 每周期拿 estPosition 更新目标；完成或失败都不自动恢复旧运动。

## 7. 模式、CAN 与持久化

### 7.1 各模式

- 当前主控实际支持 SEQ、INT、TRJ（当前与 SEQ 同分支处理）、TUN；在这些位置参考模式检测有效运动跟随误差，触发后统一取消并锁定。
- TRQ/SRV 枚举存在但当前主控未完整实现，不借此扩大本次任务。未来 TRQ 静态力矩不能套用位置误差三条件；SRV 需独立运动意图及更新超时约束。
- J8 正常 HAND 操作无普通堵转检测，不参与七轴联动堵转；CALIBRATION 接触检测只在专用、限时、限速、限流上下文开启。

### 7.2 CAN 方案（拟定，最终占用须在实现前复核）

保留 StdId=nodeID<<7|cmdCode 与现有 0x0A 数值。复用 STOP token/确认/重试/位置同步流程，扩展内部保护动作和状态，不另建独立解锁通道。

| 命令码 | 拟定用途 |
| --- | --- |
| 0x0A | 现有软停控制/确认，扩展本次保护准备、回退授权/续约、保持等内部动作 |
| 0x0B | 保护事件/状态：事件号32位、阶段、原因、版本/标志，总长8字节 |
| 0x0C | 对指定节点、会话及事件的确认；确认不解锁 |
| 0x30 / 0x31 / 0x32 | 设置暂存参数 / 查询参数 / 参数响应 |
| 0x33 | 配置事务 BEGIN/COMMIT/SAVE；整组验证后原子发布到单节点 |
| 0x34 / 0x35 | 内部受控动作上下文及确认，供寻限位等专用动作使用，具体定义在校准分析后补齐 |

配置载荷建议：操作/参数号、16位事务号、32位值，共8字节；整数或 float32 按参数类型明确规定，不能同一个参数同时解释两种单位。

事件必须按节点保存；主控采用 ISR 安全的每节点状态记录，避免单全局 event/node/cmd 被覆盖。事件带启动会话与递增编号，重复可确认、旧事件不覆盖新事件。CAN 忙使用非阻塞有界重试，不因输出失败进入永久 Error_Handler。

电机接收有效保护事件后可本地联动停止；需专门接受该协议的其他节点帧，不放宽所有外部命令。总线完全失效时无法保证远端联动，各节点本地保护及通信看门狗仍应生效；没有有效主控授权不自主盲退。

内部回退授权需有限有效期并续约；STOP/DISABLE 撤销后迟到授权不得重启。会话、事件、阶段、参数版本均要匹配。物理寻限位与普通回退不共用一份可被覆盖的目标。

### 7.3 串口、查询与 EEPROM

建议命令：`#STALL_GET n`、`#STALL_SET n KEY value`、`#STALL_SAVE n`。n=1～7 指定节点；n=0 对该功能仅展开 J1～J7，不能改变 CAN ALL=所有八节点的现有定义；n=8 查询明确报告 EXCLUDED，设置普通保护参数拒绝为 UNSUPPORTED。

示例：`#STALL_SET 4 CURRENT_A 2.0`、`#STALL_SET 0 TRIGGER_MS 150`、`#STALL_SET 4 BACK_DEG 5.0`、`#STALL_SET 7 BACK_MM 5.0`。ALL 设置为逐节点事务，不能声称跨八节点原子提交；部分成功要列失败节点，全部同步有效前禁止使用混合版本保护配置。

建议支持显式 EEPROM 保存：扩展使用独立版本、长度、CRC，保持旧 BoardConfig 布局兼容；不直接往旧结构中插字段破坏已有数据。仅在允许的失能/安全阶段持久化，不在20kHz中断中擦写。CRC不能代替掉电原子性，应定义异常配置回退/锁定行为。

当前 FLASH 校正表/用户区与链接区重叠边界需加入构建检查，避免新代码增长侵占数据区。是否需要扩容先测算实际空间，不先改所有分区。

## 8. RGB 时机

堵转锁存即切入堵转灯效意图；成功回退但保持锁定时仍保留。pending START 不恢复；最终 Started ok 或 Disabled ok 后恢复相应状态灯效。回退失败仍为保护灯效。本期仅预留调用/状态，不扩展灯效实现。

## 11. 验证计划

1. 误触发：启动、换向、连续 INT、TUN、承重静止、编码器噪声、间歇满足，J8正常夹持不参与；确认计时严格清零。

3. 自动回退：5°/5mm、不同减速比、实际反馈到位、边界截短、固定保持、不恢复旧目标。
4. 回退失败：再次受阻、无方向、无空间、超时、无有效反馈、掉线、总线忙/丢包、范围过期；每类原因明确可查询，失败不自动解锁。

7. 参数：运行修改/模式切换与计时、事务/部分失败、EEPROM旧数据迁移及损坏、回退前后普通参数完全一致。
8. 队列：SEQ/INT/TRJ/TUN、系统命令、旧epoch、USB/UART半包和迟到CAN目标均不在解锁后恢复。
9. 编译：主控与35/42/57/gripper四构建，FLASH保留区检查；主机反馈测试不替代用户实机烧录验收。

### 12.2 推荐流程

1. 收到`!CALIBRATION`先检查主控状态；使能/使能过渡/失能待确认时返回`error CALIBRATION require DISABLE`，不自动入口失能、不保留待执行校准。STOP/保护锁定中不能拿CALIBRATION解锁，须先DISABLE。主控冷启动的DISABLED标志不等于八节点已确认失能。
2. 建立本次检查编号及忙态，以新查询确认八节点全部在线、实际失能、有效编码器及控制参数；任何节点使能、缺失或状态未知都不能置原点或开始运动。再确认六轴停稳，才清旧任务/目标及普通运动世代进入校准。当前六轴姿态将被认作REST，软件不主动摆姿，也不能自行验证实际机械姿态。
3. 获取八轴真实当前位置。推荐J1～J6全程保持失能，仅对本次需要运动的J7/J8进行内部受控使能；J8的专用停止/取消不改变正常用户STOP排除J8的规则。不能借用ALL使能让六轴沿旧目标动作。
4. J1～J6将捕获位置定义为本地相对0，主控initPose及本次候选坐标同步为REST_POSE；六轴保持失能，不改电流、不发Resting、不广播ALL原点操作。后续若六轴在失能中被移动，真实反馈仍须更新，不能把显示永久写死为REST。
5. 串行处理J8：沿开度减小方向受控寻闭合端→接触后减速/固定位置→小距离退让及慢速复触确认→把最终闭合接触位置定义为开度0→按已有映射返回100→真实位置到位并判稳→捕获全开保持点。
6. 串行处理J7：沿逻辑正方向受控寻正端→接触/停稳→退让及慢速复触确认→最终接触位置定义为+250mm→返回0mm（负逻辑方向250mm）→真实位置到位并判稳→捕获中心保持点。
7. 收齐本次坐标版本及运动完成确认，J7实际回到0、J8实际回到100并判稳；取消内部运动授权，自动向J1～J8发DISABLE，必须收齐本次失能确认。此时校准忙态仍不退出，不能把失能当校准成功。
8. 在全轴失能下逐节点保存本次校准数据到EEPROM，收集任务/版本匹配的保存结果并从实际Flash回读验证。全部确认后同步主控实际当前位置与规划起点，清旧队列和pending START，退出忙态至DISABLED，返回`!CALIBRATION ok`及最终失能状态，不重启、不自动使能。

推荐J8先、J7后，防止两者同时动作和事件覆盖。步骤4～6的原点先作为本次任务的候选坐标，内部动作使用候选坐标；外部正常运动入口始终关闭，避免部分轴刚改原点即接收普通目标。

### 12.3 受控原点设置与坐标公式

内部新增“将固定捕获位置定义为指定相对电机位置”的动作，允许设0或其他标签，并返回实际生效值与版本。不是再发送现有仅置0的0x15。

设实际连续编码器位置为Q，51200单位/圈为S，目标原点标签对应的有符号相对电机圈为r：

`runtimeHomeOffset = Q_capture − r × S`

- J1～J6：r=0，主控加REST_POSE，因此当前位置显示REST。
- J7正限位：r=−250/5=−50，因此runtimeHomeOffset=Q_limit+50×S；返回地轨0的绝对目标为runtimeHomeOffset。
- J8闭合端：r=0，runtimeHomeOffset=Q_closed；返回开度100的目标为Q_closed−(100/360×16)×S。

原点更新不改传感器给出的实际连续位置Q及单圈采样历史；在停稳且入口锁定的20kHz控制路径更新偏移/版本，并重新建立goal、soft、捕获点和规划状态。J1～J6设置坐标不解除失能；对校准中正在位置保持的J7/J8，保持积分按当前正常保持电流连续衔接，避免更新原点后沿旧目标跳动。

原点改变必须使旧范围配置、迟到目标、旧事务失效；主控缓存只能由本次确认同步，不能靠先把显示数值写成REST/250/0来证明电机完成。两阶段暂存/生效可以保证单节点原子更新，CAN上的跨节点提交并非真正原子；部分提交失败必须保持忙态/保护并报告节点及坐标版本，禁止混合坐标运动。

### 12.4 预期限位与异常堵转

普通检测与校准接触检测共用测量、滤波、严格连续计时工具，但分开动作上下文和事件原因：

- 只有本次有效的J7/J8 SEEK_LIMIT任务可以把预期方向的接触解释为CONTACT_LIMIT；不永久关闭保护开关，也不让任意CURRENT静态夹持产生此事件。
- 受控寻限位有参考速度/积分参考行程。低实际速度、高电流命令、参考与实际行程的误差连续满足阈值才是接触候选；电流命令始终按命令值命名。
- 有有效旧坐标时限制候选接触窗口：J7正端附近（建议±5mm）、J8闭合端附近（建议±5开度点）；提前远离预期端点受阻，不改原点。无可靠旧坐标时，用真实累计搜索行程、方向、复触一致性限制，并明确采用无中途障碍的操作前提。
- 建议首次接触后J7退让1mm、J8张开2开度点，再以0.25电机r/s复触。两次实际接触位置差初值≤0.01电机圈（J7为0.05mm，J8约0.225开度点），不一致报CONTACT_UNSTABLE。复触不能证明中途障碍就是机械末端，不能承诺消除该物理不可辨识性。
- 已在物理端点时允许零初始行程的接触候选，再用退让/复触确认；不能强制先移动一段才检测。若无法退让，明确失败，不能继续增大力或认作成功。
- J7寻限位期间已知位置窗口外受阻、返回0期间受阻，属于异常堵转：取消CALIBRATION并转第4节正常七轴保护/自动5mm回退流程。有可靠方向与约束才能回退，不能回退须说明原因。
- J8异常受阻仅作为CALIBRATION失败事件，取消整个校准并停止内部动作；J8不因此加入普通全机堵转检测，不给J8套用5°/5mm保护回退。
- 无有效编码器、搜索超时/超行程、无高电流接触但参考已走完、坐标确认缺失，都不得记录物理限位或返回ok。

### 12.6 STOP / START / DISABLE 与失败

| 校准期间事件 | 推荐行为 |
| --- | --- |
| STOP | 立即撤销SEEK/RETURN/复触/提交授权和pending START；停止J1～J7，另通过有效校准上下文停止J8；停稳固定后转用户STOP锁定；不会自动继续剩余校准 |
| 用户DISABLE（运动阶段） | 取消校准运动，八轴失能，收到确认后Disabled ok；报告cancelled及已生效掩码。未完成校准不自动保存部分原点，不返回校准ok |
| 自动DISABLE（正常收尾） | 仅在J7/J8全部返回并判稳后进入；八轴失能确认齐全才执行SAVE，继续保持校准忙态 |
| START（检查/运动/自动失能/保存阶段） | **用户已确认：拒绝，返回error CALIBRATION busy，不挂起**；清本次进入前遗留的pending START，避免保存过程中或完成后自动使能。校准成功最终仍DISABLED，用户之后重新START。第2/4节堵转回退中的提前START决策不改变 |
| STOP/DISABLE（保存已开始） | 保持八轴失能；不能随意中断已开始的Flash擦写。完成或明确失败当前写入，取消未开始的后续保存，报告已保存掩码及取消结果；不能因取消发完整校准ok，也不能重复擦写已成功节点 |
| 普通运动/参数/HAND/CALIBRATION重复命令 | 忙态拒绝，返回CALIBRATION busy；不排队，不覆盖保护目标 |
| 超时、反馈/节点异常、接触不一致、坐标部分提交 | 取消内部动作、停稳健康节点固定保持，报节点/阶段/原因及已完成掩码，进入保护；不返回ok、不偷偷回旧原点继续运动 |
| 失败后新的START | 健康反馈下只保持当前捕获位置并解除用户锁定；坐标无效轴的普通运动仍受坐标有效性门禁限制，可重新发CALIBRATION；不可安全保持则明确故障不放行 |

候选原点可在尚未发布时撤销；已实际生效的原点不能只把主控缓存改回旧值。记录每节点本次版本、已生效/待保存状态；取消或部分失败后用真实回包恢复一致视图，必要时保持锁定并要求重校准。

J8内部停止仅在有效校准任务中允许；普通STOP仍不停止正常夹持。CAN续约与取消编号确保主控未收回包、节点重启或迟到帧不会重新启动寻限位。

### 12.7 上电默认100与自动失能保存（2026-10-06已明确）

**用户已确认上电当前位置定义为开度100，保持默认失能，上电不运动。** 在电机首次有效编码器采样时建立本地开度100参考，不改编码器实际样本、不每个周期重新定义原点、不每次上电写Flash；正常START仍保持当前位置。只有CALIBRATION使夹爪沿开度减小方向寻0，确认闭合限位后记0，随后按已确认映射返回100。

单圈编码器无法识别掉电期间的整圈位移，EEPROM保存零点不能解决多圈绝对位置恢复。必须明确区分ASSUMED_BOOT与本次实测校准坐标；主控单独重启时查询仍运行的电机位置，不能重新把电机坐标改成启动默认值。

当前模拟EEPROM写入会擦写F103内部Flash，函数位于Flash，没有校准期间保持闭环的RAM执行链；`eeprom_buffer_flush()`返回void，也不能证明写入成功。依据：[emulated_eeprom.cpp](E:/Dummy-code/firmware_new/dummy-motor-fw/Port/Platform/Memory/emulated_eeprom.cpp:213)、[eeprom_interface.h](E:/Dummy-code/firmware_new/dummy-motor-fw/Port/Platform/Memory/eeprom_interface.h:90)、[链接脚本](E:/Dummy-code/firmware_new/dummy-motor-fw/STM32F103CBTx_FLASH.ld:79)。不能把“在主循环写而非ISR写”当成不会影响20kHz闭环。

**用户已选择自动保存工序**：运动阶段先在RAM生效；全部返回原位并判稳后自动八轴失能；确认齐全后逐节点有界保存及校验；全部保存成功才返回`!CALIBRATION ok`。成功文本同时证明本次校准运动、全轴失能和EEPROM保存完成，替代此前“用户另发DISABLE后保存”和“ok仅表示RAM完成”的建议。无需为本流程增加保持闭环的RAM Flash擦写链。

EEPROM保存方案必须补充以下确认：

- 保存命令绑定本次任务、数据/坐标版本，重发只查询/继续本次状态，不能重复擦写或叠加原点。
- 单节点保存超时建议2秒；全部采用非阻塞任务推进，不把八节点Flash写入放在主控CAN ISR内等待。超时报告节点，保持失能，不无限重试。
- 校验应读取实际Flash内容并检查版本/CRC/数据；现有eeprom.get使用RAM缓存，不能将刚写入缓存的值当持久化回读证据。
- 任一节点保存失败不返回校准ok，列missing/failed/saved掩码；所有节点继续失能，失败节点的数据有效性明确记录。
- 部分节点保存或掉电不具备跨八节点原子性；不能声称全部持久化成功。原点确认、保存确认、最终完成分别计数，迟到确认不能用于下一次任务。
- 最后自动DISABLE是用户已明确要求的流程，UI校准提示应说明最终全轴失能及需要支撑当前六轴姿态；不默默恢复使能。

### 12.8 校准CAN与串口

复用前述0x34上下文、0x35状态/确认与0x0A保持/取消基础，定义SEEK_LIMIT、RETURN_TARGET、SET_CAPTURE_COORD、COMMIT_COORD、CANCEL及SAVE_COORD内部操作；操作必须带任务/阶段编号和版本，完整参数先事务暂存再提交。8字节容纳不了完整参数组时使用多帧事务，不能塞入未定义的隐含单位。

回执建议：入口不符`error CALIBRATION require DISABLE`；接受`!CALIBRATION pending`；进度`CAL J8 SEEK`/`CAL J7 RETURN`/`CAL DISABLING`/`CAL SAVING`；成功严格按用户要求`!CALIBRATION ok`并报告最终失能；失败`error CALIBRATION J7 seek_timeout`或`error CALIBRATION J4 save_failed`；取消`error CALIBRATION cancelled STOP`。机械返回或发出保存命令都不单独回校准ok。现有Respond仅64字节缓冲，新回执每行必须小于64字节，逐行诊断，不扩大为无关长文本USB修复。

### 12.10 校准验证计划

- J1～J6：只改坐标、编码器物理位置不跳、保持输出连续、各inverse方向正确，旧目标不再下发；正在运动时拒绝。
