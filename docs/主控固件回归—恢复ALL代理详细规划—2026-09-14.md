## 一、问题

### 1.1 症状

`!START` 后 RGB 灯效卡死、串口无响应。电机能响应使能。

### 1.2 根因

`DummyRobot::SetEnable` 在 v2.7/v2.8 重构中将 1 帧 CAN 广播使能（ALL 代理）改为 8 次串行 `CtrlStepMotor::SetEnable` 调用（6 个关节 + 地轨 + 夹爪）。ASCII 线程最长阻塞 ~240ms，叠加 5kHz 实时环与信号量争夺，RGB/USB 表现为"卡死"。

### 1.3 修复方向

恢复 ALL 代理（覆盖 J1~J6 + 地轨）+ 夹爪独立指针：

| 操作 | 当前实现 | 修复后 | 帧数对比 |
|------|----------|--------|---------|
| `SetEnable(true)` | 8 次串行 CAN 0x01 | 2 帧 CAN：motorJ[ALL] + hand | 8 → 2 |
| `Reboot()` | 8 次串行 | 2 帧 | 8 → 2 |
| `UpdateAngle()` | 4 组轮询（每轴 25Hz） | motorJ[ALL] 单帧 | 4 → 1 |
| ASCII 线程阻塞 | ~240ms | ~5ms | -235ms |

## 二、ALL 代理机制

### 2.1 电机端 CAN filter 配置

所有电机端 CAN filter 配置为全接收（Filter=0/Mask=0），可接收任意 StdId。

```c
sFilterConfig.FilterIdHigh     = 0x0000;
sFilterConfig.FilterIdLow      = 0x0000;
sFilterConfig.FilterMaskIdHigh = 0x0000;
sFilterConfig.FilterMaskIdLow  = 0x0000;
sFilterConfig.FilterMode       = CAN_FILTERMODE_IDMASK;
sFilterConfig.FilterScale      = CAN_FILTERSCALE_32BIT;
```

→ 任何 StdId 都被电机端 CAN 控制器接收。

### 2.2 ALL 代理原理

主控代码：

```cpp
motorJ[ALL] = new CtrlStepMotor(hcan, 0, false, 1, -180, 180);
motorJ[ALL]->SetEnable(true);
```

`CtrlStepMotor::SetEnable` 内部：

```cpp
txHeader.StdId = nodeID << 7 | mode;  // 0 << 7 | 0x01 = 0x01
// ... 发 1 帧 CAN, StdId=0x01
```

电机端如果保留 `id == 0` 特判：

```c
uint8_t id  = (RxHeader.StdId >> 7);
uint8_t cmd = (RxHeader.StdId & 0x7F);
if (id == 0 || id == boardConfig.canNodeId) {
    OnCanCmd(cmd, RxData, RxHeader.DLC);
}
```

→ 1 帧 StdId=0x01 即可被所有电机识别为广播，所有节点响应。

### 2.3 实施前提

**新版电机固件已删除 `id == 0` 特判**，必须恢复（见 R9）。否则 ALL 代理的 StdId=0x01 帧被电机端丢弃，`!START` 等命令完全失效。

## 三、最终设计

### 3.1 对象层

```cpp
class DummyRobot {
    CtrlStepMotor* motorJ[7] = {nullptr};
    // motorJ[0]=ALL(广播代理,ID=0), motorJ[1..6]=J1~J6(ID=1~6)
    CtrlStepMotor* rail = nullptr;   // 地轨独立指针（ID=9；ALL 广播时也会响应，但主控不再单独发帧给 rail）
    StepHand* hand = {nullptr};      // 夹爪独立指针（ID=8，不在 ALL 范围）
};
```

**关键点**：

- `motorJ[]` 数组大小保持 **7**（motorJ[0..6] = ALL + J1~J6）
- `motorJ[ALL]` 通过 `nodeID=0` 编码 1 帧广播覆盖 **J1~J6 + 地轨**（ID=1~6, 9，共 7 个节点）
- `rail` 是独立指针，仿 `hand` 模式；对象层保留 `rail` 是为了**接收 CAN 0x23 回包路由**（见 R8）
- `rail` 不主动发任何 CAN 帧（不发使能、不发位置、不发查询）
- `hand` 不在 ALL 代理范围：hand 单独 1 帧 CAN 0x01 发往 ID=8

### 3.2 广播机制对照

| 广播类型 | 触发 | 机制 | StdId | 接收节点 |
|---------|------|------|-------|---------|
| **ALL 代理** | `!START` / `!DISABLE` / `!REBOOT` / 位置轮询 | `motorJ[ALL]`（nodeID=0） | 0x01 / 0x7F / 0x23 | J1~J6 + 地轨（ID=1~6, 9） |
| **专用广播帧** | `!STOP`（急停）/ `!STALL_UNLOCK` | 直接写死 StdId | 0x89 / 0x5B | 全节点 |

专用广播帧不依赖 ALL 代理：`BroadcastEStop()` / `BroadcastUnlock()` 是独立函数。

### R8：can_protocol.cpp 增加 rail 路由（D1 方案关键改造点）

**文件**：`firmware/ref_core_f405/UserApp/protocols/can_protocol.cpp`

`case 0x23` 中**增加 `id == 9` 分支**路由到 `rail->UpdateAngleCallback`：

```cpp
case 0x23: {
    if (id >= 1 && id <= 6)
        dummy.motorJ[id]->UpdateAngleCallback(*(float*)data, data[4]);
    else if (id == 9)                                    // ★ D1 新增：地轨回包路由
        dummy.rail->UpdateAngleCallback(*(float*)data, data[4]);
    break;
}
```

**为什么必须改**：

D1 方案让 `motorJ[ALL]->UpdateAngle()` 1 帧广播查询 J1~J6 + 地轨（共 7 个节点）。每个电机回包时 StdId 带自己的 nodeID（1~6 或 9），主控 CAN Rx 解析时必须按 id 区分路由目标，否则地轨回包会被丢弃。

### R9（前置）：电机固件 CAN Rx 回调恢复 `id == 0` 特判

> ⚠️ **必须先烧录电机固件**，否则主控发 ALL 代理帧被电机端丢弃，`!START` 失效。

**文件**：

- `firmware/motor_fw_f103_35/Core/Src/can.c`（35 电机：J4~J6）
- `firmware/motor_fw_f103_42/Core/Src/can.c`（42 电机：J1~J3）
- `firmware/motor_fw_f103_57/Core/Src/can.c`（57 电机：地轨）
- `firmware/motor_fw_f103_gripper/Core/Src/can.c`（夹爪：保险起见一并改）

**位置**：`HAL_CAN_RxFifo0MsgPendingCallback` 函数

**改动**：

```c
// 旧
if (cmd >= 0x50 && cmd != 0x5C) {
    OnCanCmd(cmd, RxData, RxHeader.DLC);
}
else if (id == boardConfig.canNodeId) {
    OnCanCmd(cmd, RxData, RxHeader.DLC);
}

// 新
if (cmd >= 0x50 && cmd != 0x5C) {
    OnCanCmd(cmd, RxData, RxHeader.DLC);
}
else if (id == 0 || id == boardConfig.canNodeId) {  // ★ 加 id==0 特判
    OnCanCmd(cmd, RxData, RxHeader.DLC);
}
```

**注意**：

- `cmd >= 0x50` 的广播分支不动（原 0x5A/0x5B/0x89 广播逻辑保留）
- 不修改 `boardConfig.canNodeId`，不影响 EEPROM
- 夹爪固件保险起见一并改（虽然 `hand->SetEnable` 发 ID=8 单播用不到 id==0，但保持一致）

### R10（前置）：CanSendMessage 信号量泄漏修复

**文件**：`firmware/ref_core_f405/Bsp/communication/interface_can.cpp::CanSendMessage`

HAL 库 `HAL_CAN_AddTxMessage` 在 mailbox 满时返回 `HAL_ERROR`（不是 `HAL_BUSY`），不释放信号量会导致永久死锁。

**旧**：

```cpp
void CanSendMessage(...)
{
    osSemaphoreAcquire(sem_can1_tx, osWaitForever);
    HAL_CAN_AddTxMessage(...);  // 失败时信号量泄漏
}
```

**新**：

```cpp
void CanSendMessage(...)
{
    if (osSemaphoreAcquire(sem_can1_tx, osWaitForever) == osOK) {
        HAL_StatusTypeDef ret = HAL_CAN_AddTxMessage(...);
        if (ret != HAL_OK) {
            osSemaphoreRelease(sem_can1_tx);  // 失败时释放
        }
    }
}
```

### 5.2 dummy_robot.cpp

```cpp
DummyRobot::DummyRobot(CAN_HandleTypeDef* _hcan) : hcan(_hcan) {
    motorJ[ALL] = new CtrlStepMotor(_hcan, 0, false, 1, -180, 180);  // ALL 代理
    motorJ[1]   = new CtrlStepMotor(_hcan, 1, false, 50, -175, 175);  // J1
    motorJ[2]   = new CtrlStepMotor(_hcan, 2, true,  50,  -75,   90);  // J2
    motorJ[3]   = new CtrlStepMotor(_hcan, 3, true,  50,    0,  180);  // J3
    motorJ[4]   = new CtrlStepMotor(_hcan, 4, true,  50, -270,  270);  // J4
    motorJ[5]   = new CtrlStepMotor(_hcan, 5, true,  50, -100,  100);  // J5
    motorJ[6]   = new CtrlStepMotor(_hcan, 6, true,  30, -180,  180);  // J6
    rail        = new CtrlStepMotor(_hcan, 9, true,  1, -250,  250);  // 地轨（仅用于接收回包路由）
    hand        = new StepHand(_hcan, 8);                              // 夹爪
    // ... 其余不变
}

DummyRobot::~DummyRobot() {
    for (int j = 0; j <= 6; j++) delete motorJ[j];
    delete rail;        // 地轨独立指针
    delete hand;
    delete dof6Solver;
}

void DummyRobot::SetEnable(bool _enable) {
    if (_enable) {
        isStalled = false;
        SetRGBMode(rgbStateEnable);
    } else {
        isStalled = false;
        SetRGBMode(rgbStateDisable);
        for (int i = 0; i < 6; i++) targetCurrents[i] = 0.0f;
        SetCommandMode(DEFAULT_COMMAND_MODE);
    }

    motorJ[ALL]->SetEnable(_enable);  // 1 帧覆盖 J1~J6 + 地轨
    hand->SetEnable(_enable);         // 夹爪独立 1 帧
    isEnabled = _enable;
}

void DummyRobot::Reboot() {
    motorJ[ALL]->Reboot();  // 1 帧覆盖 J1~J6 + 地轨
    hand->Reboot();         // 夹爪独立 1 帧
    osDelay(500);
    HAL_NVIC_SystemReset();
}

void DummyRobot::UpdateJointAngles() {
    motorJ[ALL]->UpdateAngle();  // 1 帧广播查询 J1~J6 + 地轨
}
```

### 5.3 StepHand（不动）

`StepHand` 继承 `CtrlStepMotor::SetEnable`，发 CAN 0x01（与旧版 `DummyHand` 行为一致）。无需修改。
