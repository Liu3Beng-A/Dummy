本轮程序在新目录实现，不修改原助手、URDF 原始导出和固件，不连接设备、不下发硬件命令。用户后续明确授权仅提交独立工程及对应文档。固件仍以实际源码为准，历史文档中的撤销功能不恢复。启动时另一工作中的普通堵转/校准“恢复默认参数”协议处于暂停状态，未纳入本轮；RGB 现有临时恢复默认属于原助手功能，正常迁移。开发期间，其他工作又在原助手及固件中新增 `#MOTOR_DEFAULT`，这些并行修改保留原样，新协议需后续同步至独立程序。

## 工程组织

- `main.py`：入口、启动选项、错误日志、离线截图/烟雾检查。
- `app/transport/`：串口连接、线程、单一写队列。
- `app/protocol/`：静态参数定义、命令与回包支持范围。
- `app/core/`：迁移业务逻辑、状态、任务、Qt 定时/投递。
- `app/ui/`：PySide6 主窗口、页面、原业务字段适配、统一主题。
- `app/visualization/`、`resources/viewer/`：离线 WebEngine/Three.js/URDF 视图。
- `app/storage/`：本地 JSON 偏好、示教点、轮转日志；加载配置不写设备。
- `resources/models/DummyRobot_URDF/`：模型副本，运行时不依赖仓库外路径。
- `tests/`：协议、任务取消、存储、模型映射与界面验证。
- `packaging/`：PyInstaller 文件夹/单文件构建、版本和图标。

## 业务迁移要求

| 功能 | 验收要求 |
|---|---|
| 串口 | 刷新、连接、断开、USB/UART4 支持范围、收发异常、关闭后释放 |
| 系统 | START、DISABLE、HOME、RESET、CALIBRATION、STOP、节点/ALL 重启 |
| 运动 | MoveJ 六轴+地轨、MoveL 六维、速度1～100、拖动发送显式开关、位置同步 |
| 示教 | 点位新增/删除/排序/命名/导入导出，顺序模式确认及匹配运动编号完成回执 |
| 参数 | PID读取/直接保存，加速度及电流应用/持久保存、同步加速度、编码器校准 |
| 保护 | 全部18项普通堵转与18项校准参数、节点范围、实际回读、快照与EEPROM保存 |
| 夹爪 | 电流开合、电流幅值、位置0～100；USB高级设置按当前接口支持范围开放 |
| RGB | 开关、亮度、颜色、自动颜色、渐变、全部动画参数、状态绑定、读取、保存、临时恢复 |
| 日志 | TX/RX/警告/错误、筛选、搜索、暂停滚动、导出、自定义命令及历史 |
| 软件 | 主题、窗口布局、轮询频率、日志上限、本地持久化 |

安全及语义保持：单一发送出口；generation 淘汰取消前命令；STOP/校准时不接受运动；旧回调不恢复任务；未知使能状态不能证明失能；发送成功不等于电机完成保存。当前 PID 不提供独立 RAM 应用/`SAVE_PID`。TRQ/SRV 不作为已实现能力。TUN 仅按照主控实际支持情况提供入口。

## 三维与坐标

模型包含10个连杆、9个运动关节（rail、Joint1～6、Hand_R/L）。全部10个STL有效，总计9,649,640字节、192,976三角面。只加载visual，避免重复collision网格。

数学对照的显示映射：J1/2/3/6同号转弧度；J4/5取反；地轨毫米除1000；两夹指位移相同，`0.026*(1-opening/100)`米，轴本身相反。模型夹指原点为全开，26mm为接近闭合。

URDF J2高度227.3mm，固件六轴正解基座高度165mm，两套基准相差62.3mm；世界视图中的MoveL目标需加入该偏移及地轨平移。导出微小倾角保留。URDF近似限位不得静默裁剪实际回读；预览限位遵守固件定义。

以上为文件及离线数学对照，不代表实机方向已验收。各轴应单独验证。三维预览不会自动下发运动。实际与目标分别保存，读取状态不会覆盖正在编辑的目标。MoveL初版显示目标标记，未加入本地逆运动学。

当前`#GETJPOS`包含六关节和地轨缓存，不包含夹爪实际开度，且回包时间不等于各电机同时采样时间。独立轮询默认5Hz，最多10Hz，单个在途请求、超时与手动读取协调。STOP锁定/校准阶段按现有助手及主控门禁暂停。夹爪显示目标开度并标明未回读，完整实际开度/锁定期间跟随需另行授权固件协议工作。

### 第一轮 UI 优化（2026-10-09）

用户本轮直接授权新工程 UI 优化。浅深主题正文与三维 HUD 统一为 14px，标题层级收敛并提高辅助文字对比；运动快捷按钮使用实色语义底，模式控件紧接置零校准，顶部按钮文案为 STOP。右侧轴编辑之外增加固定夹爪区，与夹爪专页共享位置、电流和拖发状态。

示教新增 MoveJ/MoveL 滑块编辑器和类型切换。存储记录使用 `type: MoveJ` + `joints[7]` 或 `type: MoveL` + `pose[6]`；名称、速度与夹爪目标开度均保留。新版导出 `schema_version: 2`，读入兼容旧版 1 及无版本 MoveJ 文件。MoveL 不含地轨，不伪造本地逆解关节，仍使用末端标记预览；夹爪目标不自动混入轨迹发送。

顺序执行采用不可变点位快照，先确认空闲 SEQ，再匹配本条 MOVEJ/MOVEL 的类型与编号；编辑或排序不会改写正在运行的目标。拖发使用尾值合并，关闭开关、选点、切换类型、显式同步、STOP、校准和断开会取消相关待发动作，避免滑块最后位置漏发或旧回调误发新填入值。

位置轮询默认 5Hz，单一在途请求，STOP/校准/参数事务期间暂停。主控 `ascii_protocol.cpp` 的 GETJPOS 读取六轴与地轨缓存，不因该请求再查 CAN；7 个两位小数的典型回包约 43B、正常限位内最长约 58B，加上 9B 命令。115200/8N1 全双工 UART 的每方向容量约 11520B/s，5Hz 接收约 215～290B/s（1.9～2.5%），发送约 45B/s（0.4%）。USB CDC 忽略波特率设置，不能把上述 UART 百分比当 USB 总线占用。CAN 自身按节点轮转：空闲约 20ms 一个节点（七轴一轮约 140ms），运动约 5ms 一个节点（理想一轮约 35ms，仍受完成查询门控影响）；串口协议无缓存年龄字段，回答及时不证明每轴数据新鲜。

最终65项离线回归通过（控制器32、存储9、Qt控件16、三维8）；compileall与Git diff空白检查通过。1366×768在实际100%/125%/150%缩放各18张页面/子页截图均完成，合计54张，浅深主题、固定发送控件、夹爪标题、示教两种编辑器及终端展开已检查。源码入口1440×900深色URDF/WebGL烟雾检查退出0。没有连接实机、重新打包、运行EXE或提交；后发MOTOR_DEFAULT接入保持后续范围。
