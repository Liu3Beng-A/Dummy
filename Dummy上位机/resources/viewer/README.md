# 离线三维视图

运行时没有 CDN 或网络依赖。Three.js 0.170.0（MIT）与 URDFLoader
0.12.6（Apache-2.0）源文件、许可证和 SHA-256 清单都在 `vendor/` 中。
依赖源：<https://github.com/mrdoob/three.js/tree/r170>、
<https://github.com/gkjohnson/urdf-loaders>。

`RobotView` 通过随机端口和随机 token 的只读 `127.0.0.1` 服务读取
`resources/viewer/` 与 `resources/models/`，不开放其他目录，不提供目录列表，
拒绝跨源请求；WebEngine 拦截全部外部网络请求。Qt WebChannel 在内存中传递
显示状态。关闭窗口会释放服务、WebChannel 和三维资源。

`ready` 仅在 URDF 和全部 12 个 STL 可视网格成功加载后发出。仅加载
visual，不加载重叠的 collision。模型、网格、脚本或 GPU 错误显示在视图中，
并发出 `status_changed`；模型失败不发出 `ready`。初始化超时是 25 秒。

## 显示映射和需要实机验证的事实

六轴输入单位为度，地轨输入单位为毫米。J1/J2/J3/J6 同号转换为弧度，
J4/J5 取反；`rail` 转为米。夹爪百分比 0 表示闭合、100 表示全开，两个
指关节都设为 `0.026 * (1-p/100)` 米，关节轴本身方向相反。

J4/J5 符号和夹爪方向来自离线数学与网格对照，尚未验证实机方向。
以上变换只用于显示，绝不修改发送到固件的角度与位移。

目标预览按当前固件/old 助手范围限制：J1 ±175°、J2 -75~90°、
J3 0~180°、J4 ±270°、J5 ±100°、J6 ±180°、地轨 ±250 mm。
实际回读不裁剪到 URDF 的近似弧度限位，避免 180° 被截为 3.1415 rad。
URDFLoader 的 `ignoreLimits` 对实际和目标都开启，目标在 Python 层按精确
固件范围限制。机械限位仍由固件负责。

固件正解采用 165 mm 基准高度，URDF 为 227.3 mm。MoveL 目标标记把基座
局部 XYZ 转为模型世界坐标，Z 增加 62.3 mm，Y 增加目标地轨位移。
其姿态轴采用输入 Rx/Ry/Rz 的 ZYX Euler 显示约定，只作为预览；本版本
没有本地逆运动学、碰撞检测或路径可达性判定。标记不会改变机械臂姿态。

实际模式在未收到位置回读时不显示伪造的实际机械臂。断连/超时保留最近
姿态并提示数据过期。固件的 `#GETJPOS` 不含夹爪实际位置，因此显示夹爪
目标开度并明确标注“无实际回读”。实际回读使用原 URDF 材质的实体模型；
MoveJ 目标位置使用浅白色半透明虚体（普通 12%、选中 22%）。MoveJ 目标模式同时显示两者，没有回读
时仅显示目标虚体；MoveL 仅显示笛卡尔目标标记，隐藏关节目标虚体，相机
按已有实际模型取景。实际模式和手柄模式隐藏目标虚体。过期回读保留实体
并标注最近姿态。
手柄 `actualOnly` 模式清除并忽略关节/地轨的选中高亮，避免旧焦点把实体底座染蓝；
返回界面后需重新选中才显示高亮。普通界面的高亮与独立 RGB 灯环材质保持。

手柄模式的夹爪独立按最近实际写出的 `!HAND_POS` 目标开度显示，
`set_commanded_gripper(percent|None)` 只更新该示意，不改变关节回读、
过期标记、界面控制的目标夹爪或 `actualGripperKnown`。后续GETJPOS仍
保留已发送开度；断连清除。页面注明“已发送目标…%（无实际回读）”。

界面 MoveJ、MoveL 与手柄控制共用软件设置中的 `#GETJPOS` 轮询开关和
1～30Hz频率；手柄模式仅显示实际实体，回读不改写手柄软件目标。关闭轮询、
STOP、校准及参数任务期间提示回读暂停；回包超时保留最近姿态并标记过期。

六个实际关节和地轨在渲染帧之间使用 `THREE.MathUtils.damp` 追随最新回读，
时间常数为 50 ms，权重随实际帧间隔计算。它用于减轻回包间隔和逐轴缓存
刷新造成的阶梯感；匀速运动的显示会有约 50 ms 的跟随延迟，停止后收敛到
收到的位置，不外推未来位置。关节按原数值插值，不按最短圆弧折返。
首次有效回读、恢复回读、数据过期/暂停及超过 250 ms 的渲染间隔直接
显示最新收到的位置；未回读时仍隐藏实体。目标预览与夹爪示意即时更新。
平滑只影响三维实体姿态，不改变 Python 保存的回读、数字标签、日志、
位置同步或任何运动指令。数字标签与提示将格式化后的 `-0.00` 显示为
`0.00`，原始回读保留。

## 可调用接口

机械臂底座、地轨控制盒及 Link1～Link5 采用相同近黑色；夹爪主体 Link6 和两个手指
使用与地轨底座 `base_rail` 相同的灰白色，RGBA 为 `[0.309803921568627, 0.309803921568627, 0.309803921568627, 1]`。
地轨采用拆分后的 `base_rail.STL` 和 `base_rail_control.stl`，均按米制、零 origin
导入。控制盒为独立 `base_rail_control` link，通过零位移/旋转固定关节连接
到 `base_rail`，不会跟随 `rail` 滑台移动；保留新导出的底板布局。
`light.stl` 为 `base_link` 的第二 visual `rgb_diffuser`，同一局部坐标和零 origin；
现有九个可动关节定义保持，另有控制盒固定关节。散光罩环心约 `[0,0,0.189967178] m`、法向 Z，半径
34.4～44.304 mm。新底座/灯环与原正确模型共同表面拟合为恒等变换，原精度和面数保留。

`set_rgb_frame(list24x3, light_on=bool)` 接收最终逻辑 RGB 整数帧与整体开灯状态，
缓存首次加载前的最后一帧；开灯状态改变时即使 RGB 相同也会更新。
省略 `light_on` 保留旧数组接口；旧调用不会用全零帧推断关灯。
通过独立 `rgb_changed` 信号更新自发光纹理，不调用姿态 `_sync`。
仅实际模型使用 288 点环形 Gaussian 混色、局部角向 UV 和浅白散光罩。
输入帧是最终 PWM 强度，不再先当作 sRGB 图片解码：先按原 RGB 强度散射，
再把每个角向点的峰值映射为带低端过渡的曲线
`0.7 * ((peak+0.003)^0.45-0.003^0.45) / (1.003^0.45-0.003^0.45)`，
再乘共同增益 `1 + 0.3 * (1-peak)^2`，以及暗部权重
`F(peak)=0.25+0.75*t²*(3-2t)`、`t=clamp(peak/0.35,0,1)`。
暗部保留较弱彩光，接近零时为前版发光量的25%，4%旋转底光约为前版的28%；
局部 PWM 达到0.35后权重严格为1，亮头和满峰保持，边界一阶连续。
三个通道同比缩放保色。零输入保持零发光，满帧纹理线性峰值为0.7。
显示端对原始 PWM 使用 60ms 时间常数
平滑后写入 RGBA16F 纹理，避免重新量化为 8 位；原始整数目标不变。
长时间暂停/隐藏后直接恢复最新目标，不按去重消息的间隔重置平滑。
RGBA alpha 保存散光后的局部 PWM 峰值，供选择性高亮增益及诊断使用，不参与透明度。
基础发光倍率为 2.5。高亮额外增益 `G(a)=1+4*t²`，
`t=clamp((a-0.35)/(1-0.35),0,1)`，其中 `a` 是局部 PWM 峰值。
约89/255以下不加额外高亮增益；该范围采用上面的暗部权重，以拉开旋转头底对比。
超过阈值按二次曲线增强，满峰增益为5。
该增益在高亮压缩之前施加，同一个系数乘三个发光通道，不修改原始 RGB 帧或纹理曲线。
散光罩保留中性灰白材质，熄灯反射倍率仍为 0.2，不按开灯状态切换外观。
亮灯时只让反射渐退及同色化，发光不受白底权重衰减。材质灰度 0.85 是线性反射系数，
不是屏幕灰度；此处“白底权重”是反射贡献，不是灯罩几何或材质透明度。
整体 light_on 仍缓存用于诊断，渐关 RGB 照常显示；不可用状态明确关灯。
底罩反射走全局 ACES，独立发光在其后相加。设发光峰值 `p=max(E)`，
`q=p/(p+0.3)`、`w=q²*(3-2q)`、`u=E/max(p,1e-8)`，
反射贡献为 `B_eff=B*(1-0.15*w)*mix(1,u,0.75*w)`，再计算 `x=B_eff+E`。
零发光时 `w=0`，保持原灰白罩；极低亮的白底变化为二阶小量，避免 0/1 跳暗。
`highlightKnee=0.8` 以下肩部 `H(x)=x`，以上为
`H(x)=k+(1-k)*(1-exp(-(x-k)/(1-k)))`。
高亮按共同峰值同比压缩 `x*H(max(x))/max(max(x),1e-8)`；使用同一个连续权重 `w`
从旧逐通道肩部渐变到同比映射，既减少高亮混色泛白，也保持不等反射的熄灯零极限连续。
最终统一转换为 sRGB。去除白底时非主通道会降低，饱和蓝/绿的总视觉明度不一定增加；
主发光通道与色比更清晰。其他模型曝光和照明保持，没有新增光晕。
模式8与独立自动动效13～16使用保留光带渐变的显示肩部：Python发送模拟器最终`effect_mode`，
经RobotView/HTML桥传给viewer共享uniform`rgbSpinCurve`；编号8及13～16取1，其余/未知取0。
颜色相同但模式变更也独立通知，不发姿态同步或设备指令；非法编号原子拒绝。
合法模式范围0～16，手动预设仍只有0～12。未知/旧数组接口恢复原曲线，不保留旧模式标记；初始化前的帧和模式一起缓存。
对现有叠加光`x`，令`P=max(x)`，`t=clamp(P/spinHighlightWhite,0,1)`、`S=t*(2-t)`，
先算原输出`old`，再按既有发光响应`w`混合为`mix(old,x*S/max(P,epsilon),w)`。
`spinHighlightWhite=4`让中间HDR档位保留差别，高亮达到参考后仍到屏幕上限；
零发光时`w=0`，熄灯底罩严格保持。该参考越大，中亮越暗、封顶越晚，过大也会压低亮头。
此分支不改纹理曲线、Gaussian sigma0.8、60ms缓动、原始PWM、高亮增益或其他模式的肩部。
原生Qt/WebGL对照中，旋转亮头主通道峰值仍255，中亮均值约253→224；
固定灯环区接近封顶的像素约49.7%→24.5%。熄灯、彩虹、同帧非旋转模式及旧接口
对照图逐像素一致；这些是桌面渲染样本，不是实物光度测量。
这属于模型显示响应，不改变设备亮度、RGB 模拟器波形、动画参数或查询频率。
模型灯环现统一逆时针校正90°（从灯环上方+Z俯视）：局部UV基向量
`DIFFUSER_U=[-1,0,0]`、`DIFFUSER_V=[0,1,0]`，逻辑源0位于−X（后），
源12位于+X（前）、源6位于+Y、源18位于−Y。每种模式及旧无模式接口共用此安装角，
纹理偏移保持0；移除了双峰（15号）的单独补偿，其总显示方向与此前保持一致。
这是模型显示安装角，不修改24路PWM编号、周期、反向设置、散光或亮度曲线。
双向汇聚（16号）在主控与上位机同步按相邻周期交替出发端：默认先由12号灯附近
（模型前方）分两路到0号灯（后方）汇聚，下个周期由后到前。设定周期为单程，
完整往返为两个周期；第二程是第一程精确循环移12灯，保留原速度、宽度及淡入淡出包络。
反向设置继续使用原相位语义，其他模式波形保持；实物往返需更新主控15.07。
旋转模式8及独立圆圈13的主控与预览源采用相同柔化算法：`rgb_simulator.py` 与主控 `rgb.cpp`
使用约1.5灯珠的余弦前沿，尾长为配置值加2灯珠，默认3对应5；
两侧在峰值、收尾及24/0接缝均一阶连续。设备配置值不变，实物需更新主控固件。
旋转4%源底光、峰值、周期/方向、33ms本地更新、10Hz查询以及此处散光/亮度映射保持。
彩虹模式3使用与主控相同的七色闭合色表：红/橙/黄/绿/青/蓝/紫/红。
`tools/generate_rgb_rainbow.py`离线在Oklab中连接七个sRGB设计锚点，按感知路径长度
均匀重采样，再转为线性RGB/PWM。负通道裁为0、超范围峰值同比缩放；
112点Q8表分别生成主控`rgb_rainbow.hpp`与上位机`app/core/rgb_rainbow.py`。
运行时只查表和插值，不作Oklab转换；24灯按`时间相位+i/24`连续取色，整圈只有一个七色周期。
这不是七个硬色块，也不使用`灯号%7`；所有灯依次经过七色、末灯经紫红过渡连接首灯。
新默认周期6000ms，设备原有保存周期/反向保留，无配置迁移或自动保存。
生成器`--check`验证两份色表；调整配色时修改生成器的`ANCHORS`后执行`--write`，
重新编译主控并重启上位机。标准RGB近似不代替实物灯珠校准；模型散光、材质及高光映射未改。
虚体材质独立、灯环无自发光；RGB 帧重复时不重发，错误帧原子拒绝，关闭后不发送。
主模型和 RGB 悬浮设置窗复用既有模拟器/渲染定时器及 10Hz 查询，无新增设备设置指令。

### 自行调整模型灯罩

`model_rgb.js` 顶部的 `DIFFUSER_STYLE` 集中显示参数，修改后重启源码版程序：

| 参数 | 默认值 | 作用 |
|---|---:|---|
| `coverGray` | 0.85 | 灰白罩的基础灰度，线性 RGB；调低会让熄灯时更灰 |
| `coverReflection` | 0.2 | 中性反射基线，决定熄灯罩的外观 |
| `coverTintStrength` | 0.75 | 亮灯反射同色化的最大强度，0～1；增大可减少白底污染 |
| `coverFadeStrength` | 0.15 | 亮灯反射整体渐退的最大比例，0～1；不衰减发光 |
| `coverFadePeak` | 0.3 | 同色化和同比高亮过渡到一半时的发光峰值，须大于 0 |
| `emissionIntensity` | 2.5 | 基础彩色发光倍率，不改变熄灯罩反射 |
| `highlightBoostStart` | 0.35 | 二次增益开始的局部 PWM 比例，0～小于1；增大可保留更多暗部 |
| `highlightBoostStrength` | 4 | 二次额外增益，最大总增益为 1 加此值；须非负 |
| `emissionLimit` | 0.7 | 满 RGB 帧的发光纹理峰值；只改这里即可同步曲线和上限 |
| `highlightKnee` | 0.8 | 线性合成开始压缩高亮的位置，须满足 `0 <= k < 1`；常用 0.7～0.9 |
| `lowLightGain` | 0.3 | 弱光额外增益；调节会影响低亮和亮头对比 |
| `dimLightFloor` | 0.25 | 相对于前版的极低亮发光保留比例，0～1；调小可进一步压暗底光 |
| `dimLightEnd` | 0.35 | 暗部衰减结束的局部 PWM 比例，须大于0且不超过1；其上亮区不变 |
| `toe` / `exponent` | 0.003 / 0.45 | 弱光过渡和曲线；较小指数让暗光更亮 |
| `smoothingSeconds` | 0.06 | 显示缓动时间常数，秒 |

亮度设置 100% 只表示配置的总亮度增益达到 1；失能、待机、呼吸阶段和扩散会
继续降低 PWM，并不总是满 RGB 帧。默认满帧纹理峰值 0.7 也不是显示器最大亮度
或实物的 70% 亮度。需要只增强亮区时调 `highlightBoostStart/Strength`，保留基础倍率。
五倍指高亮压缩前的发光增益；已接近显示上限的像素不会显示为五倍亮，最终由柔和肩部压缩。
以上参数均只影响模型，绝不下发到设备；不要用整个场景的曝光调灯罩。

`set_rgb_preview(bool)` 仅在 RGB 窗口可见期间允许灯效示意。普通界面尚无
位置回读时，实体材质模型临时使用本地目标姿态显示，标注“灯效预览 · 本地示意”，
隐藏重叠虚体；`actualKnown`、实际姿态、回读年龄和过期信息均不被修改。
首次真实回读立即使用实际值，不从示意姿态插值；关窗恢复原无回读显示。
手柄 `actualOnly` 模式保持只显示已有实际回读的规则，不启用该本地示意。

`RobotView(parent=None)`：`ready` 和 `status_changed(str)` 信号；
`set_target_pose(list7, gripper_pct=100)`、`set_actual_pose(list7, gripper_pct=None)`、
`set_display_mode('preview'|'actual')`、`set_target_cartesian(list6|None)`、
`set_theme('light'|'dark')`、`set_stale(bool)`、`set_actual_known(bool)`、
`focus_joint(1..8|'J1'..'J8'|'Joint1'..'Joint6'|'rail'|'gripper')`、
`reset_view()`、`set_camera_view('front'|'side'|'top'|'isometric')`、`cleanup()`。
网格和坐标轴设置：`set_grid_visible(bool)`、`set_axes_visible(bool)`；
兼容别名 `set_show_grid` 与 `set_show_axes`。

目标虚体的独立显示偏好：`set_target_visible(bool)`，桥状态 `targetEnabled` 默认 `true`。
关闭只隐藏关节目标模型及其图例，不修改实际回读、目标姿态或 MoveL 标记；
`actualOnly`、实际跟随模式和 MoveL 标记仍优先遵守原来的可见性规则。

有效七轴回读与目标一致时，`targetMatched` 自动隐藏重叠虚体；关节各误差不超过
0.1°、地轨误差不超过0.1mm视为一致，隐藏后任一误差超过0.2°/0.2mm才恢复，
避免临界回读抖动。编辑新目标后重新按0.1阈值判定。同一目标重复刷新不重置回差。
