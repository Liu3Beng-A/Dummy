# Dummy Robot 上位机

独立的 Windows / PySide6 机械臂控制台，以开发开始时 `串口助手_old.py` 的协议与业务行为为基线，带离线 URDF 三维显示、示教、参数、保护/校准、RGB 和终端页面。

## 启动

在本目录运行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

启动不会连接设备或自动执行运动。仅使用主控USB虚拟串口，波特率为固件定义的115200；顶部不再提供USB／UART4选择框。旧UART4偏好读取时归一为USB，随后保存本地设置时持久化。默认配置与日志存放于 `%LOCALAPPDATA%\DummyRobot\`，可以用 `--data-dir` 指定便携数据目录。

未连接时，点击“刷新”按主控USB身份自动选中串口；先开软件、后给机械臂上电也可刷新选中，不会自动连接。已连接时刷新保留当前端口；多个主控且当前选择无法匹配时提示手动选择。

RGB保存会暂停后台关节与RGB查询，先等待已有编辑和回读排空，再单独发送保存；收到设备明确结果后恢复查询。保存期间不接受重复保存或普通控制，模型灯光保留上次显示。若6秒仍未确认，连接保留、查询继续暂停，请断开重连核实，软件不会自动重发保存。保存已发出后的STOP/DISABLE请求会等设备确认Flash结束后优先发送；尚未发送保存时则直接取消保存。此规则也覆盖RGB设置命令末尾独立的`&`。

```powershell
python main.py --data-dir .\build\preview-data --size 1366x768
python main.py --smoke-test --snapshot .\build\preview.png --data-dir .\build\smoke-data
python -m unittest discover -s tests -v
```

## 参数编辑与最近回读（2026-10-17）

电机 PID、加速度、电流限制及堵转保护/限位校准参数分别保留最近回读、编辑草稿和本次请求快照。读取只更新未修改的输入；已修改的字段继续保留，旁边显示新的回读值。切换节点或页面不丢草稿，数字格式不同但数值相同不会标为修改。

地轨（节点7）首次未回读的PID编辑值为 `KP=150、KV=180、KI=25、KD=50`，与2026-10-17电机固件工厂默认一致；这只是本地初始值，不代表设备回读，也不会自动发送。已有草稿和真实回读优先，设备已有有效EEPROM也不会因固件升级被覆盖。完整要求与生效条件见[地轨PID默认值调整记录](../docs/地轨PID默认值调整_20261017.md)。

PID 区域直接在每个参数下方显示作用、调大后的倾向及过大时的表现，四列按当前宽度所需的最大文字高度对齐，不额外预留大块空白；回读和编辑状态变化不改变说明高度，无需打开说明窗口。内容按当前电机 DCE 位置闭环编写：KP 校正位置偏差，KV 累计速度偏差，KI 累计位置偏差，KD 直接校正速度偏差并提供阻尼作用。说明只读，不发送指令；保存 PID 直接写 EEPROM，“还原编辑”只恢复输入，不撤销设备写入。

参数区在深浅主题中使用统一层级：名称14px、输入16px，回读/状态12px、辅助说明13px。未修改且未读取、无查询或回读过期时用灰色；有效回读与编辑一致用柔和绿色；修改、等待确认用黄色；无效输入或当前请求明确失败用红色。颜色只解释当前编辑状态，绿色不代表EEPROM物理保存完成。状态槽固定20px，颜色变化不改变布局。

电机参数、保护校准与夹爪配置的输入和操作按钮统一36px高；保存为蓝色主按钮，读取/应用为普通按钮，还原编辑弱化，擦除配置保持危险色。保护表将最近回读和编辑状态上下对齐在一列，夹爪高级配置采用两列字段并将保存按钮对齐输入框。PID四列保持按文字所需高度收紧；布局只随窗口宽度适配，参数回读或状态变化不会推动页面。RGB浮窗复用状态配色，其他控件保持原布局。

- “还原编辑”只把最后一次有效回读复制到编辑框，不发送指令。尚未回读的字段不能还原；断连后保留的回读标为过期，恢复连接后需重新读取核实。
- 发送后继续编辑，旧请求的回执只更新该请求结果，不清除新草稿。主控确认转发、回读值一致和 EEPROM 保存成功是不同证据，不能互相替代。
- 夹爪高级 PID/加速度使用节点8的电机回读；电机电流限制与 `!HAND_I` 运行电流独立。速度和上电行为没有专用查询接口，明确显示无回读，不使用初始默认值冒充设备值。
- RGB 保留现有本地草稿合并逻辑，并提供编辑状态与本地还原。上述状态始终占用固定区域，文本变短或提示变化不会推动布局。没有自动查询、重发、失能或设备运动。

## 配置应用与保存反馈（2026-10-17）

RGB、电机参数、堵转保护/限位校准和夹爪配置的应用与保存使用统一的非模态提示。主窗口共享状态区域共用一个固定提示位，操作反馈淡出后恢复状态原因；RGB 浮窗有自己的固定提示位。操作所在页面另有一行“最近结果”。提示不弹窗、不抢焦点、不移动页面或自动切换窗口，文本过长时省略，悬停可查看完整结果和下一步。输入错误会在可定位的数值框上标色，编辑后清除。

- 处理中持续显示；成功提示约3秒，条件不符/参数错误约5秒，失败或结果未确认约6秒后淡出。页面的最近结果持续保留，同一任务的进度直接更新原提示。
- RGB 的明确 `ok RGB saved` 以及堵转/校准参数的完整节点确认才显示设备确认成功。PID、加速度、电流限制和夹爪持久配置的现有主控回执仅确认请求转发，显示“电机写入结果未回报”，不冒充 EEPROM 写入完成。
- 缺少失能确认、接口不支持、参数错误、超时或断连均说明原因及建议操作；没有自动失能、重试、附加查询或放宽原有条件。后台关节/RGB 回读不会产生提示，也不会覆盖最近操作结果。
- 普通配置校验与结果不使用需手动关闭的弹窗；原有擦除 EEPROM、编码器/置零校准等危险动作确认保留。

## 当前运动路线（2026-10-13）

普通运动仅由主控执行：手动目标、鼠标、手柄及示教发送原生 MoveJ / MoveL。软件已撤下上位机逆解运动后端及规划进程接入；旧 `host` / `stream` 设置仅在本地迁移为 `firmware`，迁移不会发送模式切换、使能或运动指令。

普通模式选择仅开放1～4。主控实际模式7仍按真实状态显示并拦截普通运动；显式恢复原生模式须核对停稳、关闭残留会话和模式回执，STOP锁保持到用户再次START。模式7仅供终端独立OPEN／恒定原地曲线诊断，不能执行目标位移。

FK、工具偏移、世界TCP与法兰转换、点位schema和全部模型／灯环显示保留。当前主控MoveL仍为终点逆解后普通关节运动，地轨保持当前位置；真正直线、笛卡尔速度和地轨自动协同属于后续主控规划。本次不修改或重新编译固件，现有13.05产物保持。以下旧批次实测和协议记录按当时版本阅读，不代表新路线已完成真机直线验收。

## 七轴原地曲线通信测试

终端支持 J1～J7 单轴、J1+J7 双轴及七轴整组，点击“2 s 原地曲线通信测试”。要求主控能力 `STREAM_AXES v=1 hz=50 mask=127 targeted=1`、USB、人工使能且静止、模式2或7；旧能力mask65仍可测原J1/J7/双轴，新增项在切模式和OPEN前拒绝。

取所选电机DIAG7的int32保持参考，发送SEED+100个20ms零速度/加速度段，不使用逆解或普通MoveJ，不下发位移。正常保持原位，误差补偿可能微动；最终101/101、接受/执行100、DONE/CLOSE及模式恢复确认。用户三组J1/J7/双轴已实测通过，先新增J2～J6单轴，再七轴整组；真实位移另安排。

单在途CAN诊断公平轮询，逐轴检查600ms健康，actual实际RX300ms门槛不变，关闭前仍核对freshness。STOP/DISABLE废弃曲线尾，关闭确认才恢复模式2，保持停止锁。断连结果未知；七轴127预START保留旧无1秒自动清理合同，重连残留会话明确拒接管。操作/资源说明见 `firmware_artifacts/axis-communication-notes-2026101303.txt`。

## 静止准入与 START 现场（2026101304）

本版配套新主控与新电机固件。电机 CAPS bit2 才表示支持新鲜50ms稳态证据和独立START快照；主控按本次真实电机CAPS输出 `STREAM_FEATURES s=token steady=mask start=mask`。旧电机或缺能力回包继续按旧瞬时速度规则解释，不查询34..50新增字段。要修复J4静止时仅瞬时估速拒绝的问题，必须更新J4对应类型的电机固件，只更新PC或主控不改变电机准入。

新电机在OPEN和START核验同一新鲜50ms位置范围/有符号平均速度窗口；目标、坐标、模式、保护、校准、反馈异常等变化使旧证据立即失效。±512均速、原位置范围/到位容差、参考速度零、精确SEED和硬保护仍保留。OPEN独立字段23..33及45..47；START独立字段34..44及48..50，前后会话校验，不以OPEN现场推测START。

发送STREAM_START后显示等待同步确认；实际确认RUNNING/DRAINING后才显示执行。数字故障与原始阶段保留主因，后续STOP_LOCKED不覆盖；人工STOP/DISABLE继续优先显示用户中断并立即废弃曲线尾。主控关闭期间的迟到电机故障也不能改写首次故障序号。

上方“诊断 / OPEN 节点”控制只读查询和OPEN→CLOSE；下方“曲线测试参与轴”控制原地曲线。两者独立，按钮显示实际目标，点击日志记录节点或mask。本轮先J4同姿态OPEN十次，逐次确认CLOSE、间隔2秒；通过后再J4原地曲线，逐轴/整组后续开展，不用MoveL替代。本版默认仍主控后端，不新增位移/逆解/标定测试。

统一烧录产物仍位于 `firmware_artifacts/`，最新操作说明为 `steady-entry-notes-2026101304.txt`；旧13.03及更早报告保留作历史。

## 单电机 OPEN→CLOSE 诊断

终端选择 J1～J7，点击“单电机 OPEN → CLOSE 测试”。需要 USB、本批主控和该电机的 OPEN 快照能力；保持默认主控模式即可。主控须已使能且静止，按钮不会代为 START。

该入口不调用逆解、不规划、不发送运动点。主控向选中电机执行 CAPS→OPEN→自动 CLOSE；上位机显示主控准入原因、OPEN 接受/拒绝、CLOSE 确认及 OPEN 瞬间的速度/位置/模式和19项拒绝位。旧固件、快照不匹配或关闭未确认均不会显示通过。

## 操作说明

- 预览和实际位置独立。拖动关节默认只更新预览；启用拖动发送后遵守原助手模式与状态限制。
- 三维实际回读显示为实体，MoveJ 目标位置显示为浅白色半透明虚体，普通透明度 12%、选中 22%；MoveL 仅显示笛卡尔目标标记，隐藏关节目标虚体。没有回读时仅显示对应目标，回读过期会保留最近实体姿态并提示。实际模式及手柄模式隐藏目标虚体。
- 模型底座及 Link1～Link5 为相同黑色，夹爪主体 Link6 和左右手指使用与地轨底座相同的灰白色。独立 `light.stl` 为浅灰白散光罩，属于底座的第二可视网格，随地轨移动且不增加关节。新导出与既有模型实测已对齐，采用恒等变换导入，原始导出保留。
- 地轨使用新拆分的 `base_rail.STL` 与 `base_rail_control.stl`，共用米制原点；控制盒为独立黑色 link，固定在地轨底座上，不随滑台移动。12个可视网格完整加载后才显示模型，原有可动关节及机械臂坐标保持。
- 实际显示保留七轴回读原值，不因超出关节或地轨限位丢弃整包，也不裁剪成限位值；例如J3回读180.62°时实体按180.62°更新，连接后未使能也能显示。非有限值、过期或倒序回读仍不更新显示。运动规划限位单独检查，超限回读不会被裁剪成合法规划起点，也不会自动写入编辑目标；显式“读取→同步输入”遇到超限会保留原编辑值并提示。
- MoveJ、MoveL、示教和夹爪拖发统一仅在 SEQ 顺序模式下提示切换到 INT 打断或 TRJ 连续模式；INT/TRJ 不再提示切换，开启拖发本身不会发送目标或自动改变模式。
- 三维显示的“网格、坐标轴、显示虚体”开关位于上方恢复画面圆圈图标右侧，中文包含在按钮内，蓝色表示开启；与软件设置双向同步并保存。底部保留鼠标操作说明，移除等轴、正面、俯视预设按钮。
- 坐标轴表示固定世界原点的 XYZ 方向，覆盖显示以免被地轨和底座挡住；其显示开关与电机使能状态无关。
- HOME / RESET 指令成功进入发送流程即切换到对应的 MoveJ 目标虚体（包含地轨归零），无需等待完成OK；按钮、终端和自定义指令共用此逻辑。本地拒绝或入队失败不改变目标，目标更新也不会额外发送MoveJ或夹爪指令。HOME为`[0,0,90,0,0,0,0]`，RESET为`[0,-75,180,0,0,0,0]`；只有匹配本次动作编号的OK才提示完成，实际实体仍跟随七轴回读。
- 运动页右下的夹爪区固定显示，切换 MoveJ/MoveL 不影响位置输入、滑块、拖发开关和电流开合；与夹爪设置页同步。
- 启动、失能、回零、休息、校准及模式控件位于“运动控制”标题右侧。速度和发送/读取紧接滑块区，窗口空间不足时仅轴区滚动。
- 三维工具栏的“显示虚体”开关默认开启，关闭后只隐藏关节目标虚体和对应图例，实际回读模型与 MoveL 目标标记不受影响。选择保存在本机，重启后恢复；手柄模式隐藏此按钮，切回界面控制后保留原选择。工具栏宽度不足时自动分两行显示。
- 运动页不显示串口日志；点击顶部“终端”打开独立日志窗口，保留筛选、搜索、暂停、导出、清空及自定义指令/历史。关闭日志窗口后仍持续记录，打开不会挤占主界面。
- 终端默认勾选“隐藏关节回读”，显示和导出时过滤 `#GETJPOS` 查询及对应的七轴位置回报；取消勾选可查看GUI已处理的回读记录。开关保存在本机，不影响轮询、模型更新或状态判断；回读超时、错误和运动完成回执仍显示。逐条原始收发保留在有界异步WIRE审计及完整诊断导出中，GUI合并策略见下方位置轮询说明。

复测前先保存正常状态的主控版本、相关电机版本及 CAN、RGB、运动状态和栈记录；逐节点查询堵转当前/LAST。出现 STOP 后，在设备仍回复的前提下再查询 CAN、堵转 LAST、运动状态及 RGB，并导出完整日志。若主控 RGB/OLED 一起停刷且串口无回复，不要连续点击查询；保留并导出已有记录，注明停刷时间、实物是否继续运动以及是否重启。LAST 为电机保存的最近一次事件，不保证跨断电保留；这组查询也不能读取已完全卡住的主控现场。

- 彩虹（模式3）为七色循环流动：红→橙→黄→绿→青→蓝→紫→红，24灯沿整圈错开1/24周期，紫红接缝连续。主控与上位机共用生成的112点色表，按感知色距分配过渡空间；新默认6秒一圈，已保存/回读的周期及方向原样保留。仅彩虹改用新配色，其他灯效、全局亮度与模型材质保持。七色设计可在仓库根`tools/generate_rgb_rainbow.py`的`ANCHORS`修改，再运行该脚本`--write`；需重新编译主控并重启上位机。色表按标准RGB近似设计，实物灯珠尚未测色校准。
- 旋转（模式8）及独立自动动效（13～16）的模型显示保留中高亮层次，避免光带过早封顶成为同亮色块；亮头尽量保持，实际零发光的灰白底罩不变。只在本地桥明确传入这些模式时启用，彩虹、呼吸、常亮及旧无模式接口继续使用原显示曲线。模式来自模拟器最终选中的效果，包含自动状态/保护覆盖；不改变RGB原始帧、散光或60ms缓动。`model_rgb.js`的`spinHighlightWhite=4`为高亮参考，详情见viewer说明。
- 三维区域左上角和 RGB 设置里的大型二维圆环均已移除，24路灯效帧在模型底座及顶栏圆环共享显示。顶栏以原生二维扩散色带显示，模型保留原三维材质；两者共用输入帧、开关状态、模式及灯效相位，设备跟随仍依据回读配置/状态本地生成，不代表已取得实物灯珠逐帧颜色或相位。模型使用环形散光混色和灰白灯罩（基础色 0.85、熄灯反射倍率 0.2、基础发光倍率 2.5）；熄灯外观保持，亮灯后白底反射随局部光量连续渐退及同色化，提高饱和度，发光独立相加。高亮逐渐转为按共同峰值同比压缩，减少混色偏白。另有选择性二次高亮增益：低亮部额外平滑压暗，4%旋转底光约保留前版发光量的28%；局部PWM达到约90/255后暗部权重为1，越亮增益越大，满峰发光增益最高 5 倍；这是压缩前增益，屏幕像素亮度受显示上限限制。运动底光保持非零，亮头峰值、60ms平滑及半精度纹理保留。实际熄灯时发光归零，目标虚体不显示灯效。显示参数集中在 `resources/viewer/model_rgb.js` 顶部 `DIFFUSER_STYLE`，修改后重启源码版；详细说明见 `resources/viewer/README.md`。这些处理只影响模型显示，不改设备亮度、灯效时序或 RGB 模拟器波形。RGB 帧走独立显示通道，不刷新关节姿态或增加查询。
- RGB 动画约30fps，在电脑本地计算；主窗口顶栏或RGB设置窗口任一可见时，复用同一刷新器，切到其他主页面仍同步显示。设备跟随时沿用一个10Hz（100ms）RGB状态监视器，完整配置与状态查询共享发送预算，不因新增顶栏重复查询。完整配置查询进行时等待其回报，缺失配置重试仍至少隔5秒。主窗口及RGB窗口均隐藏或最小化时暂停动画与查询；完整配置在连接、设置回执或缺少有效配置时获取，手动查询按钮仍可立即查询。
- 终端默认“隐藏 RGB 回读”，过滤 `#RGB_GET`、`#RGB_STATUS` 及结构化 RGB 回报，可取消勾选恢复显示；设置命令、警告和错误保留。普通导出遵守隐藏开关，完整诊断导出、缓冲及磁盘日志包含全部记录。
- 内置 STOP 默认采用黄色 `(255,180,0)` 双心跳，与新固件一致，周期固定 1800ms；使用设备回读的其他自定义 STOP 绑定时仍按其配置模拟。

位置轮询是上位机主动发送 `#GETJPOS`，默认 5Hz，可在软件设置中调整为 1～50Hz 或关闭。界面 MoveJ、MoveL 和手柄控制共用这一条七轴回读逻辑，不轮询 `#GETLPOS`；只更新实际模型，不覆盖编辑目标或手柄软件目标。任意时刻只保留一条位置查询在途；30Hz使用34ms定时，实际频率受调度及回包耗时限制。主控返回已有的七轴缓存，不因该指令新增 CAN 查询；按正常数值长度估算，5Hz 在 115200/8N1 UART 上占接收带宽约 1.9～2.5%、发送约 0.4%。USB CDC 的波特率设置不是实际 USB 吞吐上限。轮询回包及时仅表示主控回答及时，协议未提供各电机缓存年龄。

三维采用按需绘制：视角操作、姿态或灯效变化时唤醒，保留相机惯性及现有显示缓动，稳定后停绘；重复的相同姿态／灯效数据不重复绘制。应用失去焦点但视图仍可见时，绘制上限15FPS；切换到其他主页面、隐藏或最小化时暂停三维绘制与该视图的WebChannel数据推送，串口接收和本地最新状态缓存继续运行。恢复显示时只发送最新快照并直接显示当前姿态，不补播隐藏期间的旧帧，也不重置视角。此策略没有增加姿态插值缓存或改变轮询周期。标题栏最大化按钮仅在悬停状态改变时重绘，减少普通鼠标移动引起的无效更新。

启动日志的`RENDER`记录包含WebGL渲染器、缩放比例及上下文丢失／恢复事件；上下文丢失时暂停绘制，恢复后继续使用当前姿态和视角。保留GPU硬件加速和系统原生外框，不强制切换图形后端。这些记录用于排查现场快速闪空白，离线测试不能证明驱动或系统合成导致的闪烁已彻底消失。

## 手柄控制

运动页右侧的输入方式可切换为“手柄”，与界面控制共用串口队列和三维视图。启动软件、切换输入方式或检查手柄都不会自动接管、使能或运动。先用“检查输入”核对设备和映射，再点击“接管控制”；手柄设置也可从软件设置页打开。

手柄模式收起八个快捷点位槽，保留“保存当前点位 / 管理”，给控制状态和 Start 留出空间；切回界面控制恢复八个槽。左侧三维视图隐藏目标模型、末端目标标记和目标预览选项，切回界面恢复原显示偏好。接管前后实际模型关节均按软件设置共用 `#GETJPOS` 轮询；关闭自动读取、STOP、校准、参数任务及断连时暂停，保留最近实际姿态并提示暂停/过期。关节软件目标不会更新实际模型，回读也不会修正手柄目标或代替到位确认。夹爪按最近实际写出的手柄 `!HAND_POS` 命令显示目标开度并注明“无实际回读”；界面控制的夹爪预览逻辑保持原样。固定夹爪区仍保留，接管时禁用其中的手动写入。

- 第一次 Start 发送使能；第二次 Start 发送一条初始化 MoveJ，默认指令为 `>0,10,80,0,90,0,0,10`；观察实物到位后第三次 Start（默认按键7）确认到位。确认只在本地进行，摇杆和扳机回中后解锁。初始化不附带模式查询、模式切换或 `#MOTION_STATUS`；通用 `#GETJPOS` 仍按软件设置更新实际模型，不参与初始化完成判定。地轨目标固定为 0mm。
- 初始化按设备当前模式执行，以其主动返回的 `queued MOVEJ` 识别模式与编号。INT 的 `accepted MOVEJ` 只表示受理，不表示到位；第三次 Start 或“确认到位”按钮均可进行本地确认。初始化回执前按 Start 不提前解锁，确认后仍要手柄回中，连续控制需预先选择 INT；在 SEQ/TRJ 下不会自动切换模式。软件目标不作为实际回读展示。单独的“休息”动作仍保留原空闲/运动完成检查。
- 手柄 MoveL 的法兰 XYZ/ABC 按串口助手 old 拖动轴的一位小数精度发送（0.1mm / 0.1°），去掉末尾无效零；old 未拖动的输入框仍可能保留原有精度，手柄则统一处理六个字段。TCP 软件目标保留完整积分精度，工具换算后才取舍发送值，相同发送内容不重复入队。没有旋转输入的姿态轴保留原表示，平移不会把 `180` 改成 `-180`；旋转轴只在越过 ±180° 时折返。MoveJ 和速度参数仍保留原三位小数精度，初始化命令仍为 `>0,10,80,0,90,0,0,10`。固件运动正文的63字节上限检查保持。
- 左摇杆控制 X/Y，右摇杆上下控制 Z；十字键控制 Pitch/Yaw，LB/RB 控制 Roll。Back 为 STOP，A（默认按键0）在已使能且接管后发送初始化 MoveJ，默认 `>0,10,80,0,90,0,0,10`；初始回执后仍须观察实物到位并按 Start 或界面确认，A 不代替到位确认，按住不连续发送。Y 进入休息姿态；B 的同步功能及“同步当前位置”按钮已取消，X 未绑定。旧配置缺少 A 映射时自动补齐；若编号0已被旧自定义功能占用，仅新增初始化键保持“未绑定”，保留原映射，可在设置中调整。手柄不提供地轨控制，初始化及休息的 MoveJ 地轨目标均固定为 0mm。
- 手柄夹爪使用 `!HAND_POS 0～100`：RT 增加开度，LT 减小开度，同时按下不改变目标。每次初始化确认后，软件目标默认100%，可直接使用扳机；确认及回中不自动发送夹爪命令。目标限制在0～100%，默认已在100%上限时按RT不增加，先按LT减小后可用RT增大。“发送夹爪位置”可显式发送指定开度并设为软件目标。三维夹爪在当前连接、当前发送代次的命令实际写出后跟随其整数开度；编辑、排队及STOP取消的命令不会更新模型。关节回包不覆盖这份开度，断连清除它；尚未发送时保持全开示意。显示值不表示实际开度，固件没有夹爪位置回读。
- 默认满杆 TCP 软件目标速度为200mm/s，轻推按去死区后的杆量比例减速；角速度50°/s、夹爪150%/s。线速度与角速度输入暂不设上限，要求有限数值且至少0.01；夹爪可设0.01～150%/s。默认速度平滑时间60ms，可在手柄设置中调整或设0关闭，回中立即停止新增位移。MoveL速度档位仍35，初始化/休息档位10；它们控制电机速度上限，不能直接换算为末端mm/s。工具长度默认114mm，表示法兰到夹爪末端的局部Z偏移；初始化法兰约为 `[146.52,0,288.92,180,0,180]`，TCP Z约174.92mm。
- 旧默认配置按版本在启动时迁移，设备映射及其他自定义设置保留。版本5将旧线速度50/角速度5更新至当时默认100/50；版本7将旧默认夹爪90更新到150，更早默认30直接采用150。版本8将旧默认满杆线速度100更新到200、运动发送间隔50ms更新到100ms，并补默认60ms速度平滑；以后明确保存的自定义速度和间隔不再迁移。迁移仅更新内存，保存设置后写入文件。旧XYZ范围及最低高度字段仅兼容保留，不用于手柄MoveL检查。
- 配置包含设备编号/GUID、轴键映射、死区和扳机范围。原始输入诊断只采集数据；第一次采集时已按住的按键不会被视为新按下。拔出后需主动重新检查并接管，不自动改用另一只手柄。
- 接管期间屏蔽界面拖发、示教和其他运动写入，STOP/失能仍可用。切换应用、主窗口与浮动终端之间切换、离开运动页、隐藏/最小化主窗口以及打开普通对话框均不主动发送 STOP，手柄继续后台采集和控制；真实输入断开或超过500ms没有有效输入仍停止。接管期间仍禁止修改手柄映射/配置和界面运动写入。切回界面输入或关闭当前已接管的窗口仍先请求STOP，确认后交接/退出。
- “释放”只退出手柄发令并撤销尚未写出的排队目标，不发送STOP，也不等待最后目标到位；已进入串口写入或主控的目标仍可能继续执行。界面显示“已释放”，不会把它显示为“已停止”；拖发保持关闭。已请求的STOP/DISABLE不会因释放而取消，仍等待已有确认；日志单独记录GAMEPAD_RELEASE。
- 当前 MoveL 收到匹配编号的 `PLAN_FAILED` 时，软件目标回退到最后受理目标并暂停增量；摇杆和扳机回中后可向可达方向重试，不发送 STOP、START 或位置查询。MoveJ的明确PLAN_FAILED只暂停该动作、回到待初始化；新目标校验失败只拒绝该目标，格式化/长度失败保留最后受理目标等待回中。最后受理目标仍可能继续运动，软件回退或目标拒绝不表示实机已停；其他运动错误、模式不符及真实保护仍按原故障门禁处理。
- HAND_POS实际写出后默认3秒内无匹配回执，仅暂停夹爪发送和扳机目标增量，不停止机械臂；界面提示发送暂停，可点击“发送夹爪位置”显式重试。单次MOTION_STATUS查询回执超时只提示，并在原查询间隔之后再查，最终关节运动超时保持。超过10秒仍未写出的任一会话指令属于发送阻塞，仍按通讯故障请求STOP；机械臂运动、使能及模式确认的回执超时仍STOP。
- 每次手柄会话主动 STOP 前记录 `GAMEPAD_STOP`：来源、原因、原状态、输入年龄/采集错误/按键、运动编号、在途指令及最近发送/回执。停止确认与释放后保留原停止记录；`GAMEPAD_TARGET_REJECTED` 单独记录被拒绝的目标，`GAMEPAD_HAND_TIMEOUT`记录夹爪回执超时。日志保存在本机原日志目录，软件不自动增加完整诊断轮询。
- 关闭时先请求停止，最多异步等待约1秒；未收到停止确认会明确记录，不能把关闭软件当作实机已停。发生输入或指令回执超时并确认 STOP 后，可再次 Start 使能和初始化；停止未确认时保持门禁。
- 手柄MoveL按固定节拍合并最新目标，默认100ms（约10次/秒），目标相同不重复发；不等每条 `accepted MOVEL` 才发送下一条。串口最多保留一条尚未写出的手柄MoveL，写出后释放发送槽，独立跟踪最多64条待受理记录；夹爪仍单条在途、默认100ms发送间隔。延迟/乱序受理不会让最后受理参考退回旧目标，旧规划拒绝不会取消更新的已写出目标；最新规划拒绝回退最后受理目标并等待回中，取消未写出后继目标。缺失运动回执仍按各条写出后的响应超时处理，不因持续新发令重置旧期限。手柄和目标面板的常规显示节流到约20Hz，状态切换、STOP及夹爪发送暂停提示立即更新。
- 位置/旋转目标缓冲以最近已写出TCP为参考，取旧配置最小缓冲和两次发送周期对应位移中的较大者（时间预算至多1秒）；超出时截断增量，不整次丢弃。回中清掉尚未排队的目标增量，已在串口写入或主控的最后目标仍可继续执行。共享GETJPOS回读只更新实际模型，不修正手柄目标；其1～50Hz频率独立于MoveL发送节拍。线速度表示软件目标生成速度，实际运动受电机档位、加速度、逆解和固件规划限制，不保证恒速200mm/s。STOP/失能、代次取消、输入断开/过期及主控保护保持原规则。
- 手柄 MoveL 不再检查软件配置中的法兰 XYZ 范围或 TCP 最低高度；5mm/5° 软件命令步长上限继续生效。可达性由主控处理，不可达目标仍按 `PLAN_FAILED` 暂停及回中恢复逻辑处理。

手柄TCP控制目标仍在右侧作为数值诊断保留，左侧保留最后实际姿态；没有本地逆解或碰撞检测，也不通过软件目标伪造实际反馈。本地正解参数与当前 `firmware_new` 一致，不包含地轨位移或 URDF 的62.3mm显示偏移；后续若修改固件机械参数，需要同步本地正解。旧配置中已退休的B键同步映射在读取时仅删除对应字段，其他映射和自定义设置保留。当前 ASCII 回包没有客户端租约，软件互斥只覆盖本程序，不能防止其他串口客户端同时发令。源码离线测试不等于实机手柄与运动验收，仍需后续确认实际映射、方向及工具长度。

输出位于 `dist/`。文件夹版须分发整个`dist/DummyRobot/`目录；单文件版为`DummyRobotPortable.exe`。资源、模型、Qt运行时随包携带，使用端不需要安装Python。USB串口设备驱动按实际硬件安装。

程序依赖PySide6、pyserial、NumPy、SciPy和pygame（手柄采集时加载），前端依赖Three.js及URDFLoader；对应第三方许可证随资源保留。项目详细方案及验证结果见仓库`docs/Dummy上位机开发方案.md`。

开发期间，另一处工作在原助手及固件中新增了 `#MOTOR_DEFAULT` 电机恢复默认事务。本轮独立程序尚未接入该后发功能；需要在其协议稳定后同步专用操作、状态门禁和回读验证。

## 七轴运动模式（0.3.0 / STREAM_JOINT v2）

启动默认使用主控模式。顶部模式选择与软件设置的后端选择共用模式门禁：主控 1～4，曲线透传 7；5/6 保留。原来通过连续普通 MoveJ 模拟直线的上位机执行后端已移除，旧 `host` 设置迁移到主控，算法模型和离线 IK API 保留。

曲线透传仅支持 USB，主控与 J1～J7 必须同为协议 v2。每个有限 MoveL/MoveJ 在独立 spawn 进程中完成规划和全部区间校验，Qt、RX/TX 和信用控制不承担逆解计算。Windows 打包入口启用 `multiprocessing.freeze_support()`；取消/关闭会回收纯计算子进程，不连接设备。

**50 Hz 是曲线边界间隔 20 ms**。USB 按 FIFO 信用预填/补充，最多四个未确认包；电机本地 20 kHz 连续执行参考。GETJPOS 为 30～50 Hz（由设置限幅），不是每个边界同步编码器采样。当前没有运行中的在线纠偏、未来缓冲重规划或跨示教点圆滑衔接。

执行流程：查询 v2 能力与空闲状态 → 关闭旧完成/故障会话 → 逐轴读取实际速度/加速度上限 → 每条点位读取 DIAG7 保持参考 → 核对实际到位 → 独立进程预检 → 再读保持参考确认未变化 → 模式 7 / OPEN → SEED、缓冲、统一 START → END 与实际稳定 → CLOSE。下一条重新读取保持参考，不复用前一条假定终点。SEED 的整数电机位置必须与保持参考完全一致；主控和电机仍是实际到位/零速的最终判定方。

原生到位允许小残差，因此实际回读不直接作为透传 SEED：J1～J5 普通到位容差 711 subdivisions，J6 426，J7 1024。主机核验另外考虑 GETJPOS 的 0.01°/0.01mm 输出量化；不会修改电机保持参考。DIAG7 是有符号的 `goalPosition-home` 细分位置；v1 在 OPEN 前拒绝。

MoveL 档位参与 TCP 时间参数化：100 档最高 20mm/s、10°/s，35 档 7mm/s、3.5°/s；约束可以进一步放慢曲线。透传不生成普通 MoveJ 速度字段。每条有限点位起止速度、加速度为零，混合示教序列在各点停稳后继续。

RX 线程直接更新执行保护的数据，300ms 无有效实际 RX 时工作线程发 STOP；界面迟滞单独显示，不会冒充实际 RX 断流。GUI 只保留最新有效遥测，33ms 刷新；同一次串口 read 的多个合法回包保留最后姿态及原时间戳，不伪造时间或速度。

停止或故障后先确认 STOP locked，再关闭旧会话、切换模式；退出到主控不要求发送 START。再次运动仍需要用户正常 START，并重新预检。关闭旧会话失败不会继续发 DIAG、OPEN 或原生运动。透传忙/拒绝具有明确原因，原始故障码及 AT/MASK/CAN/T 上下文保存在日志。

串口 RX/TX 在 observer 之前由独立日志线程记录，包含真实读取/写出时的 wall/monotonic 时间和顺序号。内存历史及落盘队列各有 8192 条上限；拥塞不会堵住控制，丢失会有计数和警告，不宣称无限日志。完整导出追加原始 wire 历史，更早记录保存在轮转磁盘日志。界面普通日志的显示时间不用于重建串口时序。

有限 MoveL、MoveJ、混合示教与鼠标最新离散目标已接入；连续手柄仅使用主控模式。TCP 标定、固定 TCP 移轨、在线重规划仍未实现。帧/工具 API 见 [dummy_motion/README.md](dummy_motion/README.md)。
