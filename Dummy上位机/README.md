# Dummy Robot 上位机

独立的 Windows / PySide6 机械臂控制台，以开发开始时 `串口助手_old.py` 的协议与业务行为为基线，带离线 URDF 三维显示、示教、参数、保护/校准、RGB 和终端页面。

## 启动

在本目录运行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

启动不会连接设备或自动执行运动。串口波特率为固件定义的115200，连接类型需选择USB或UART4；界面根据当前固件接口开放功能。默认配置与日志存放于 `%LOCALAPPDATA%\DummyRobot\`，可以用 `--data-dir` 指定便携数据目录。

```powershell
python main.py --data-dir .\build\preview-data --size 1366x768
python main.py --smoke-test --snapshot .\build\preview.png --data-dir .\build\smoke-data
python -m unittest discover -s tests -v
```

## 操作说明

- 预览和实际位置独立。拖动关节默认只更新预览；启用拖动发送后遵守原助手模式与状态限制。
- 三维显示的“网格、坐标轴”开关位于上方“复位视角”右侧，蓝色表示开启；与软件设置双向同步并保存。底部保留鼠标操作说明，移除原来的四个视角按钮。
- 坐标轴表示固定世界原点的 XYZ 方向，覆盖显示以免被地轨和底座挡住；其显示开关与电机使能状态无关。
- HOME / RESET 在匹配到本次动作编号的完成 OK 后，模型切换到相应的 MoveJ 目标预览（包含地轨归零）；仅受理的 pending 回执不会更新模型。实际位置仍由设备回读更新。
- 运动页右下的夹爪区固定显示，切换 MoveJ/MoveL 不影响位置输入、滑块、拖发开关和电流开合；与夹爪设置页同步。
- 启动、失能、回零、休息、校准及模式控件位于“运动控制”标题右侧。速度和发送/读取紧接滑块区，窗口空间不足时仅轴区滚动。
- 运动页不显示串口日志；点击顶部“终端”打开独立日志窗口，保留筛选、搜索、暂停、导出、清空及自定义指令/历史。关闭日志窗口后仍持续记录，打开不会挤占主界面。
- 终端默认勾选“隐藏关节回读”，显示和导出时过滤 `#GETJPOS` 查询及对应的七轴位置回报；取消勾选可查看保留的完整收发记录。开关保存在本机，不影响轮询、模型更新或状态判断；回读超时、错误和运动完成回执仍显示，磁盘轮转日志保留完整记录。
- 夹爪下方提供 4 个示教点快捷加载位置，按列表顺序显示前 4 个已存点位。点击载入对应 MoveJ/MoveL 目标、速度与夹爪预览，仅更新输入和三维显示；执行使用原发送按钮。“管理”进入点位示教，改名、更新、排序、删除及导入后快捷区同步刷新。
- 快捷区的“保存当前点位”允许命名并保存运动页当前 MoveJ/MoveL 编辑目标、速度和夹爪开度，不主动查询或发送设备指令。取消或文件写入失败不会新增点位；超过 4 个点位后可在“管理”中调整快捷显示顺序。
- 提示和点位命名窗口随浅色/深色主题显示高对比正文，标准操作按钮使用中文；确认/取消及默认选项语义保持原样。
- 地轨位置单位为mm，关节为°，速度档位1～100，100对应电机轴30r/s。
- MoveL 默认法兰目标为 `[146.52,0,288.92,180,0,180]`（XYZ 为 mm，ABC 为 °），与手柄初始化关节姿态对应；Z 滑块上限为 300mm。
- STOP是固件软停命令。回执状态及未知/超时分别显示。
- 左侧“电机设置”集中电机相关功能；顶部两个二级标签左右等分，左侧为“电机参数”，右侧为“电机点位校准”，包含原有堵转保护、限位校准及快照查询。
- PID保存通过当前`#SET_PID`直接写EEPROM；加速度、电流限制及保护参数按页面区分临时应用与持久保存。
- 示教编辑器可切换 MoveJ（六轴+地轨）与 MoveL（X/Y/Z、A/B/C），支持滑块、数值和显式拖发。选择点位、切换类型及同步实际位置只更新编辑/预览，不自动运动。
- 示教列表可混合两类点位；顺序执行先确认空闲 SEQ，再等待匹配运动类型及编号的完成回执。夹爪开度用于预览，不随点位轨迹自动发送；MoveL 不移动地轨。
- 点位导出使用版本 2，旧版本 1 或无版本的 MoveJ 文件仍可导入；旧版软件不支持新的 MoveL 点位文件。
- 本地偏好和示教文件只保存在电脑，加载文件不会自动写入设备。
- RGB 内容区左侧 60% 编辑参数，右侧 40% 显示连续白色散光灯环；24 灯的光线经邻近混色柔化后显示，灭灯为灰白罩体。支持全部 13 种灯效、亮度与渐变、旋转方向/拖尾和设备状态模拟，适配浅深主题。
- 颜色选择窗口使用中文及对应浅深主题，保留基础色、自定义色、拾取屏幕颜色、RGB/HSV 和 HEX 输入。确认后更新本地颜色，取消保留原值；选色不会自动发送设备指令。
- 默认“本地编辑预览”：改颜色、动画参数或状态绑定立即试看，不发送指令。右侧灯效、状态及“模拟开灯”也只作用于预览；左侧“应用”及开关按钮仍控制设备。“设备灯效切换”按钮会发送命令。
- 切换“跟随设备配置”后，圆环使用完整回读的配置与状态，保持独立动画相位和估算亮度；顶部“当前”亮度来自设备，圆环中的“模拟”值由电脑推算。未连接、未完整回读或状态超过 3 秒未更新时明确提示，编辑左侧参数会自动回到本地预览。
- RGB 动画约 30fps，在电脑本地计算；设备跟随仅在 RGB 页可见时约 1Hz 查询状态。离开该页、隐藏或最小化窗口暂停动画与查询；完整配置只在连接、设置回执或缺少有效配置时获取。

位置轮询是上位机主动发送 `#GETJPOS`，默认 5Hz，可在设置中调整为 1～10Hz 或关闭。主控返回已有的七轴缓存，不因该指令新增 CAN 查询；按正常数值长度估算，5Hz 在 115200/8N1 UART 上占接收带宽约 1.9～2.5%、发送约 0.4%。USB CDC 的波特率设置不是实际 USB 吞吐上限。轮询回包及时仅表示主控回答及时，协议未提供各电机缓存年龄。

## 手柄控制

运动页右侧的输入方式可切换为“手柄”，与界面控制共用串口队列和三维视图。启动软件、切换输入方式或检查手柄都不会自动接管、使能或运动。先用“检查输入”核对设备和映射，再点击“接管控制”；手柄设置也可从软件设置页打开。

手柄模式收起四个快捷点位槽，保留“保存当前点位 / 管理”，给控制状态和 Start 留出空间；切回界面控制恢复四个槽。左侧三维视图隐藏目标模型、末端目标标记和目标预览选项，切回界面恢复原显示偏好。手柄接管及释放确认期间暂停位置查询，视图保留最近实际回读并提示暂停/过期，软件目标不会更新实际模型；选择手柄但尚未接管时，普通轮询仍按原偏好运行。固定夹爪区仍保留，接管时禁用其中的手动写入。

- 第一次 Start 仅发送使能；第二次 Start 只发送初始化 MoveJ，默认指令为 `>0,10,80,0,90,0,0,10`。不附带模式查询、模式切换、位置查询或 `#MOTION_STATUS`。地轨目标固定为 0mm。
- 初始化按设备当前模式执行，以其主动返回的 `queued MOVEJ` 识别模式与编号。INT 的 `accepted MOVEJ` 只表示受理，不表示到位；观察实物到位后点击原“初始化”按钮变成的“确认到位”，手柄回中后才能连续控制。这个确认只建立本地软件目标，不发送串口命令。连续控制需预先选择 INT；在 SEQ/TRJ 下不会自动切换模式。软件目标不作为实际回读展示。单独的“休息”动作仍保留原空闲/运动完成检查。
- 手柄 MoveJ / MoveL 保留原三位小数精度，去掉小数末尾的无效零。固件运动队列的正文上限为63字节，软件在发送前检查该上限；原初始化正文52字节（含换行53）未超限，紧凑格式正文20字节（含换行21）。
- 左摇杆控制 X/Y，右摇杆上下控制 Z；十字键控制 Pitch/Yaw，LB/RB 控制 Roll。Back 为 STOP，Y 进入休息姿态；B 的同步功能及“同步当前位置”按钮已取消。手柄不提供地轨控制，初始化及休息的 MoveJ 地轨目标均固定为 0mm。
- LT/RT 控制夹爪开合。先明确设置“建立夹爪目标”，再用扳机连续调整；没有基准时不会自动跳到全开或全闭。显示的是软件目标，固件没有夹爪实际开度回读。
- 默认 TCP 目标平移速度 50mm/s、姿态目标旋转 5°/s、夹爪 30%/s，MoveL 速度档位 35，初始化/休息档位仍为 10。线速度控制摇杆推动目标的速率；速度档位作为 MoveL 最后参数，控制主控电机上限，档位35对应最高10.5r/s、100对应最高30r/s（电机轴），各轴按同步规划进一步降速。实际 TCP 速度还受加速度等因素影响，并非恒速50mm/s。工具长度默认 114mm，表示法兰到夹爪末端的局部 Z 偏移，可在未接管时修改。初始化软件控制起点的法兰约为 `[146.52,0,288.92,180,0,180]`，工具朝下，TCP 的 Z 约为 174.92mm。
- 旧配置中的原厂工具长度、初始化姿态、Z 上限、线速度10mm/s及MoveL档位10在启动时迁移至新默认值，设备映射及其他自定义设置保留；后续明确保存的自定义值不会再次被迁移覆盖。
- 配置包含设备编号/GUID、轴键映射、死区和扳机范围。原始输入诊断只采集数据；第一次采集时已按住的按键不会被视为新按下。拔出后需主动重新检查并接管，不自动改用另一只手柄。
- 接管期间屏蔽界面拖发、示教和其他运动写入，STOP/失能仍可用。释放、切回界面、离开运动页、最小化、失去焦点或打开对话框会退出连续控制；恢复窗口不会自动重新接管。
- 关闭时先请求停止，最多异步等待约1秒；未收到停止确认会明确记录，不能把关闭软件当作实机已停。发生输入或指令回执超时并确认 STOP 后，可再次 Start 使能和初始化；停止未确认时保持门禁。
- MoveL 与夹爪各保留一条在途指令并合并最新目标，默认最短间隔分别为 50ms、100ms；MoveL 上限20次/秒，实际受Qt调度和回执耗时影响，目标不变时不发。线速度是软件目标的生成速率，档位是电机速度上限，两者没有固定换算；线速度过大且档位过小时实物可能跟不上，INT会持续覆盖旧目标，取消位置回读后不能监测或自动修正真实跟随误差。手柄接管期间不发送 `#GETJPOS` 或 `#GETLPOS`，也不启动替代的位置反馈查询。默认5mm/5°限制改为软件目标相对最近已受理指令的步长，只在本次匹配的发送及受理确认后推进基准，不能判断相对实物的超前或跟随误差。输入过期、发送/回执超时、保护和断连仍锁定连续控制。回中只停止目标增量，最后已发目标仍由主控处理。

手柄TCP控制目标仍在右侧作为数值诊断保留，左侧保留最后实际姿态；没有本地逆解或碰撞检测，也不通过软件目标伪造实际反馈。本地正解参数与当前 `firmware_new` 一致，不包含地轨位移或 URDF 的62.3mm显示偏移；后续若修改固件机械参数，需要同步本地正解。旧配置中已退休的B键同步映射在读取时仅删除对应字段，其他映射和自定义设置保留。当前 ASCII 回包没有客户端租约，软件互斥只覆盖本程序，不能防止其他串口客户端同时发令。源码离线测试不等于实机手柄与运动验收，仍需后续确认实际映射、方向及工具长度。

## 三维显示边界

所有模型与前端脚本来自本目录，支持离线加载。六轴、地轨和左右夹指联动；相机操作不会发运动指令。

显示映射来自URDF与固件正解的离线数学对照：J4/J5取反，地轨mm转m，夹爪开度反向映射至0～26mm。实机方向尚待逐轴确认。URDF基准比固件基座高62.3mm。

当前位置回包包含六关节和地轨，夹爪实际开度未提供，视图只显示夹爪目标值。STOP/校准门禁期间暂停位置轮询并显示过期/暂停状态。MoveL目标以位置标记展示，未实现本地逆运动学、碰撞检测或物理仿真。

## EXE 构建

**2026-10-09 状态：按用户要求暂停打包验证。** 首轮文件夹包已构建，但启动时 QtCore DLL 加载失败，尚未修复及验收。现有 `dist/` 为排查产物，请通过上面的 Python 入口继续开发和测试；下列命令留作后续构建说明。

```powershell
python -m pip install -r packaging\requirements.txt
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
# 文件夹包验证后再生成单文件版
powershell -ExecutionPolicy Bypass -File packaging\build.ps1 -OneFile
```

输出位于 `dist/`。文件夹版须分发整个`dist/DummyRobot/`目录；单文件版为`DummyRobotPortable.exe`。资源、模型、Qt运行时随包携带，使用端不需要安装Python。USB串口设备驱动按实际硬件安装。

程序依赖PySide6、pyserial和pygame（手柄采集时加载），前端依赖Three.js及URDFLoader；对应第三方许可证随资源保留。项目详细方案及验证结果见仓库`docs/Dummy上位机开发方案.md`。

开发期间，另一处工作在原助手及固件中新增了 `#MOTOR_DEFAULT` 电机恢复默认事务。本轮独立程序尚未接入该后发功能；需要在其协议稳定后同步专用操作、状态门禁和回读验证。
