# 夹爪固件 (motor_fw_f103_gripper)

基于 `motor_fw_f103_35` 的夹爪专用固件，针对 35 步进电机 + 16:1 减速比夹爪优化。

## 特性

- 固定 CAN 节点 ID = 8（忽略拨码开关）
- 默认电流限制 1.2A（适合夹爪工作）
- 禁用堵转检测（夹爪在力矩/位置模式下不应触发堵转保护）
- 位置模式自带电流限制（DCE 输出受 ratedCurrent 钳制）
- 参数可通过 CAN 命令实时修改并存储 EEPROM

## 默认参数

| 参数 | 值 | 说明 |
|------|----|------|
| CAN ID | 8 | 固定 |
| 电流限制 | 1.2A | 可通过 0x12 修改 |
| 速度限制 | 30 r/s | |
| 加速度 | 100 r/s^2 | |
| DCE Kp | 195 | |
| DCE Ki | 300 | |
| 堵转保护 | 禁用 | |
| 自动使能 | 禁用 | |

## CAN 命令

StdId = `(nodeID << 7) | cmdCode`，其中 `nodeID = 8`。

### 控制命令（无 EEPROM 存储）

| 命令 | 功能 | 数据 |
|------|------|------|
| 0x01 | 使能/失能电机 | uint32: 1=使能, 0=失能 |
| 0x03 | 电流模式 | float (A)，发送电流目标值 |
| 0x04 | 速度模式 | float (r/s) |
| 0x05 | 位置模式 | float (圈)，带 ACK |
| 0x07 | 位置+速度限制 | float[2] (圈, r/s) |

### 参数命令（可存储 EEPROM）

| 命令 | 功能 | 数据 |
|------|------|------|
| 0x12 | 设置电流限制 | float (A)，第5字节=1存储 |
| 0x14 | 设置加速度 | float (r/s^2)，第5字节=1存储 |
| 0x15 | 应用零点偏移 | 自动存储 |
| 0x1B | 设置堵转保护 | uint32: 1=启用, 0=禁用 |

### 查询命令

| 命令 | 响应 StdId | 返回值 |
|------|-----------|--------|
| 0x21 | 0x3A1 | 电流 (float A) |
| 0x22 | 0x3A2 | 速度 (float r/s) |
| 0x23 | 0x3A3 | 位置 (float 圈) |

## 主控命令映射

主控通过 ASCII 协议发送：

```
!HAND_POS <0-100>   → 位置模式开合（夹爪自动限流至 ratedCurrent）
#I_LIMIT_J 8 <0.05-2.0> → 设置夹持力上限（发送 CAN 0x12 到电机）
!HAND_O             → 电流模式张开（发送 0x03 负电流）
!HAND_C             → 电流模式闭合（发送 0x03 正电流）
```

### 夹爪工作流程

```
1. !HAND_POS 0       → 夹爪完全张开
2. #I_LIMIT_J 8 0.8  → 设置夹持力 0.8A
3. !HAND_POS 80      → 轻柔夹取（力度上限 0.8A）
4. !HAND_POS 100     → 全力闭合（力度上限 1.2A 默认）
```

## 与通用固件 (motor_fw_f103_35) 的区别

| 特性 | 夹爪固件 | 通用固件 |
|------|---------|---------|
| CAN ID | 固定=8 | 拨码开关 0-7 |
| 默认电流 | 1.2A | 2.0A |
| 堵转保护 | 默认禁用 | 默认禁用 |
| 适用场景 | 夹爪 | 地轨、臂关节 |

## 编译

```bash
mkdir build && cd build
cmake -DCMAKE_BUILD_TYPE=Release ..
make
```

输出：`Ctrl-Step-STM32-Gripper-fw.hex` / `.bin`
